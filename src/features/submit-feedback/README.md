# Submit Feedback

- 职责：承载顶栏“建议反馈”用户动作，包括反馈类型单选、文字描述、本地截图预览、取消与提交交互。
- 入口：消费者只从根 `index.ts` 导入 `SubmitFeedbackDialog` 及公开类型。
- 约束：当前没有反馈接口契约；组件不会发起请求、上传文件或伪造成功提示。可选 `onSubmit` 只把受控草稿交给调用方，顶栏当前未传入该回调，因此提交仅关闭并重置静态表单。
- 扩展：后端提供单一业务接口、字段限制与文件上传契约后，在本 feature 内接入并补充校验、提交中、错误和成功反馈；不得为缺失字段拼接额外请求。
- 验证：PC 对照 Figma 节点 `1097:36682`；平板/H5 采用同一语义表单和弹窗滚动，视觉与真机兼容由用户验收。运行 test/lint/build。
