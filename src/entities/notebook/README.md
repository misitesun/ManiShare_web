# 笔记本实体

- 职责：维护笔记本、课程包笔记页与章节笔记页共同使用的笔记组、记录、课程包和章节索引及静态演示数据。
- 入口：根 `index.ts` 暴露类型、一级分页 fixture、`findNotebookCourse`、`createCourseNoteGroups`、`getNotebookChapters` 与 `findNotebookChapter`。
- 约束：课程关联只保存 `coursePackageId`，不导入同层 course-package；页面分别读取两个实体进行组合。数量表示静态句子笔记组数量，组内可包含多条记录。示例内容来自设计稿，不代表课程真实内容；无接口、持久化或跨页面编辑状态。
- 扩展：真实数据接入后用已校验模型替换 fixture；课程与笔记关系、计数口径及删除后的服务端同步需按确认的接口实现。
- 章节 fixture：每个有效课程包展示八章，每章包含截图中的两组笔记，组内记录分别为两条和三条；标题与正文沿用截图示例。组、记录及行 ID 按课程包与章节隔离；无效课程或章节不回退成第一章。卡片数量由 groups.length 得出，课程包概要保留原设计演示数量，两者不代表真实汇总关系。
- 验证：同目录测试覆盖无效路由参数、所有分页卡片的详情查询、设计记录数量及跨课程稳定 ID；运行 test/lint/build。
