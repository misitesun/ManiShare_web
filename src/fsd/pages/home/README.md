# 学习首页

- 职责：承载 `/` 静态学习首页，编排公告、注意力进度、学习留言、统计、成果展示边框占位、月度学习花盆、预留区与今日风云榜。
- 入口：`index.ts` 仅导出 `HomePage`；页面私有 UI、演示数据与资源不对外暴露。
- 约束：当前不请求接口、不实现排行榜或学习统计业务状态；榜单上方固定展示前三名，下方以 50 条页面私有 mock 数据在独立容器中滚动。首次进入首页且未确认定位提示时主动打开共享 `TldDialog`；点击确定仅持久化“提示已确认”，不会调用浏览器或系统定位 API，关闭弹窗不写入确认状态，刷新后仍会提示。公告与留言只做本地循环动画并尊重 reduced-motion。学习花园的日期项共用 `TooltipGroup`，相邻日期间切换时保留单一 Portal 并平滑移动内容，不改变原有横向滚动和键盘聚焦行为。排行榜舞台使用页面私有 React Bits Light Rays 源码替代位图背景，顶部居中紫色光束参数由页面固定，颜色经主题 token 注入，舞台底色直接继承当前主题画布。PC 以 1920×1080 Figma 为视觉基准，首页最大宽度为 1720px 并在超宽主内容区内居中；750px 以下统计指标改为每行一条并左对齐，原成果展示区移除文案、视频封面和播放标识，仅保留圆角边框与 241px 占位高度。
- 资源：定位提示图标来自 Figma 1097:37299，并保存在页面私有资源目录；已移除成果展示专用播放图标与封面数据；留言头像仍由原模块保留。排行榜光束改编自 React Bits Light Rays（MIT + Commons Clause），使用项目已有 `ogl`，不再保留旧舞台背景位图。
- 降级：光束画布限制 DPR 为 1.5，仅在进入视口且页面可见时持续渲染；粗指针设备不启用鼠标跟随，`prefers-reduced-motion: reduce` 下冻结首帧，WebGL 不可用时保留当前主题画布与完整排行榜内容。尺寸、主题、指针、可见性、动画帧和 WebGL context 必须随页面同步或清理。
- 响应式字号：常规标题、正文和标签使用全局语义字号阶梯；排行榜舞台数字与会员徽标因固定几何保留页面局部规格，1920px 为设计上限。
- 高度约束：三列网格使用明确高度 `max(1001px, 100dvh - 80px)`；1001px 为 713px 首行、241px 次行、15px 行距与32px 内边距之和。排行榜网格项设置 `min-h-0`，列表只在自身容器滚动；不能仅设置网格最小高度，否则长列表的固有高度会撑大 `1fr` 行。
- 响应式布局：H5 与平板使用单列，`lg` 在紧凑桌面宽度使用两列，视口达到 1440px 后恢复设计稿的三列两行位置关系并流式收缩列宽，到 1920px 时使用设计稿固定列宽。PC 三列布局以扣除 80px 顶栏后的视口高度为最小高度；1080px 设计高度保持 713px / 241px 基准，更高视口由学习花园和排行榜列表承接增量，不缩放文字、图片或顶部卡片。排行榜领奖台必须基于自身容器宽度分级缩放，不得仅根据视口断点强制使用原尺寸。
- 扩展：真实公告、留言、学习记录或排行榜接口确认后，再按独立业务动作与稳定领域对象判断是否进入 `features` / `entities`；页面私有区块不得因文件长度机械提升到 `widgets`。
- 验证：`leaderboard-data.test.ts` 固定榜单 mock 数量、排名区间与设计稿首屏数据；运行 `pnpm run test && pnpm run lint && pnpm run build`。Codex 仅验收 PC，平板与 H5 由用户人工验收。
