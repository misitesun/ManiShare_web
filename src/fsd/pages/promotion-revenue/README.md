# 推广收益页面

- 职责：承载推广链接、收益概览、可提现信息、佣金、提现和注册明细的静态分页展示。
- 入口：根目录 `index.ts` 导出 `PromotionRevenuePage` 和 `PromotionRevenuePageProps`，由 `/promotion/revenue/` 路由懒加载。
- 约束：当前统计值、邀请信息、佣金和注册记录均为页面私有静态演示数据，不代表真实结算规则；复制、提现以及真实数据请求尚未接入。
- 页签边界：复用 `TldSegmentedTabs` 的content/comfortable/generous变体，靠左排列、选中线覆盖文字，位移时保留灰色底线；佣金和注册明细是页面私有静态分页，提现复用 `widgets/withdrawal-records` 的contrasted外观，与分公司保持同一字段、数据、分页、二维码和Tooltip契约，分公司保留默认外观。
- 提现交互：共享提现区块负责收款码弹窗、审核说明 Tooltip 和静态分页，页面不得保留实现副本。
- VIP小管家：页面私有`VipStewardQr`把概览IP形象作为按钮；鼠标悬停或键盘聚焦打开，移入浮层保持显示，离开延迟120ms关闭；键盘焦点仍在入口时保留显示，Escape、离开入口/浮层后的失焦或外部点击关闭。触摸点击切换，点击二维码会把焦点移入浮层并保留显示，从浮层按Escape关闭后恢复入口焦点；路由卸载清理计时器、监听和Portal，不持久化状态。
- 响应式：H5 默认纵向排列，平板扩展统计网格，PC 在宽屏下对齐 1920px 设计稿；表格窄屏时局部横向滚动。
