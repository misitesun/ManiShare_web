# 我的收藏页

- 职责：承载 `/profile/favorites/` 静态收藏管理页，按 Figma 展示六段课程分类页签、响应式收藏卡网格、触底分页以及浏览/编辑两种状态。
- 入口：`index.ts` 导出 `FavoritesPage`，仅由 app router 懒加载。
- 约束：当前使用页面私有静态数据，课程摘要和封面从 `entities/course-package` 获取；分类页签只筛选当前内存列表。点击“编辑”后整张卡片可多选，“取消”清空本次选择并回到浏览态；删除前必须经共享 `TldDialog` 确认，确认后只从当前内存列表移除。不虚构服务端接口、持久化或失败反馈。
- 扩展：接入收藏接口时先以 `unknown` 校验 DTO，再补齐 loading/empty/error、真实分页、取消收藏提交及反馈；服务端契约确认前不建立 API 边界。
- 响应式：≥1920px 时以侧栏右侧主内容区为基准左右各留 250px，取消版心最大宽度，网格按最小 290px 卡宽自动排布列数并顶部对齐，分类筛选后不足两行时不拉伸卡片；1280～1919px 不设版心最大宽度，左右统一各 16px，既有列数不变；同一视口和侧栏状态下与其余四页内容边界对齐；平板/H5 边距不变。
- 封面：PC、平板与 H5 的封面容器均为 3:2，图片填满容器并使用 `object-cover` 等比裁切；封面高度随卡片宽度变化，不保留固定 200px 高度。文字区保持 82px，页签、网格、间距和整卡选择覆盖层沿用现状。
- 字号：页签、编辑操作、卡片标题、分类和笔记数量使用全局响应式语义字号，1920px 保持设计稿上限。
- 验证：`model/favorite-items.test.ts` 覆盖分类识别与筛选，`model/pagination.test.ts` 覆盖分页状态，共用 `features/edit-course-collection` 测试覆盖编辑、多选、取消与删除。运行 `pnpm run test && pnpm run lint && pnpm run build`；PC 在 1920×1080 及超宽屏核对 690px 页签、250px 边距、自动列数、3:2 封面及选择覆盖层与卡片边界一致；768×1024 平板与 390×844 H5 的视觉及真机兼容由用户验收。

- 统一封面动效（2026-10-19）：课程封面复用 [TldTiltedCover](../../shared/ui/tld-tilted-cover/README.md)，沿用本页既有槽位、比例和圆角，只让内部图片随鼠标倾斜/轻微放大并显示光泽。原链接、播放入口、选择和角标保持；收藏/作品编辑态停用动效。触屏与减少动态效果保持静态，离开/失焦/滚动/卸载清理；PC交互专项与平板/H5待用户验收边界见公共组件说明。
