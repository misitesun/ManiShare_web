# 畅学 VIP 页面

- 职责：承载 `/vip/` 的会员分类、黄金/终身卡、联创天使介绍、免费体验展示和本地领取演示。
- 入口：仅从根目录 `index.ts` 导出 `VipMembershipPage`、页面 Props 与用户会员状态类型；私有 UI、状态和资源均保留在本 page。
- 事实来源：黄金周/月/季/年卡分别来自 Figma `3:7803`、`1886:12918`、`1886:13306`、`1886:13694`；联创天使 `3:8183`，免费体验未领取 `3:8472`，已领取 `1922:14619`。
- 约束与数据边界：无请求、支付、真实领取、真实分享、计时器或存储写入。四种黄金卡均按稿保留199/年、原价399、立省200、每天0.54；终身卡699/终身、原价1999，不推算其他价格。免费体验3天、已分享0人、0天00:00:00固定展示；二维码为设计图标，不包含真实入群地址。
- 周期权益：`getGoldVipPlan` 根据受控周期生成完整方案。周卡发放1000魔晶；月/季/年卡分别月发6000/8000/10000；每日评测100/300/800/3000次；答疑周期及首单10%/20%/25%/30%分享奖励同步切换。终身卡月发12000、无限次评测、赠送1v1答疑、首单40%分享奖励保持独立。
- 用户状态：`viewer.activeProductIds` 是会员状态适配点；默认展示“立即购买”，包含对应产品 ID 时展示“立即续费”。黄金周期和本地体验领取状态由页面持有，切换分类不丢失；初始未领取，点击只切换“已领取”并原生禁用，刷新恢复初始状态，不宣告真实领取成功。
- 交互：初始选中畅学VIP；三分类受控切换。联创天使展示四列权益、介绍和“这就去看看”，只通过app注入路径跳转现有 `/collaboration/`。分享链接、会员购买/续费及客服入口沿用统一未接入提示。
- 顶部切图：紫/绿柔光来自 `3:8454/3:8455` 的SVG，以CSS background-image展示，不再用CSS椭圆模拟。分类栏外框来自 `3:8462`，128px/162px选中背景来自 `3:8077/3:8467`；仅背景层导出2倍透明PNG，文字/翅膀保持DOM，免费体验复用同尺寸128px背景。角向渐变已在资源中烘焙，避免外部SVG的foreignObject渐变兼容问题；改稿须重新导出背景，不用均匀CSS border替代。资源不包含整页截图或交互文案。
- 设计基准：1920×1191 CSS视口、100%缩放、展开侧栏。页头32/38，副标题24/29，分类栏x812/y240、496×54，选中背景128×38或162×38、文字16/24。体验卡与黄金卡x564/1069、y335，470×742，按钮410×50/r12；体验标题26/36、数据34/48、正文16/22、权益14/20，俱乐部区域410×95，脚注灰色。联创面板x562/y328、996×276，四列154/135/178/179、间距80，图标34，标题20/28，正文16/22；按钮498×50、16/22，咨询入口y1128。
- 响应式：H5默认、md平板、xl桌面；双卡在H5/平板单列最大470px，xl双列。联创权益默认单列、md两列、xl四列；连接加号仅在四列时展示。分类栏窄屏按内容分配，背景装饰单独适配，不缩放画布/字号或反向抵消浏览器放大。H5/平板视觉、真机和实际浏览器125%/150%/200%缩放交由后续验收。
- 共享影响图：复用根入口 `TldButton` 与 `TldSegmentedTabs`。新增 `TldButton size="plan-compact"`（50px/r12、16/22）及 `variant="subtle"`（轻表面与独立禁用文字/边框），原尺寸和变体默认值不变；黄金卡继续使用plan和neutral页签。`app/styles`新增完整dark/light的联创面板、权益强调和体验按钮token，原VIP柔光token由切图替代并移除。无路由、存储、环境、依赖、Electron bridge变化。
- 兼容性：遵守Next静态运行时与主题切换契约；初始渲染不依赖视口、随机值或浏览器存储，背景和图标静态导入；主题继续由shared/theme处理，reduced-motion沿用共享组件策略。字体遵循系统回退，不保证特殊字体字形跨系统一致。
- 扩展：真实会员、领取、分享和入群等待独立接口任务；联创介绍卡不跨slice导入 `/collaboration/` 私有UI或资源。
- 验证：`VipTrialPanel.test.ts` 覆盖两种展示状态、按钮禁用范围和静态数据；周期与共享按钮保留就近测试。运行 `pnpm run format`、`pnpm run test`、`pnpm run lint`、`pnpm run build`；PC核对设计几何、三分类、领取/回切/刷新、跳转、主题、资源加载和生产水合。平板/H5视觉与真机待用户验收。
