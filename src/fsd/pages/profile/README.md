# 玩家档案页

- 职责：承载 `/profile/` 玩家资料静态页面，按 Figma `1:3739` 展示个人信息、会员与学习摘要、邀请入口和 Mani 陪伴展示。
- 入口：`index.ts` 导出 `ProfilePage`，仅由 app router 懒加载。
- 约束：页面当前只呈现设计数据，不发起接口请求、不读写存储；复制、编辑、绑定、升级、注销、退出和二维码保存均不接业务行为。退出及二维码保存复用共享 `TldButton`，按设计稿正常显示、保留按钮原生交互外观，但不绑定点击处理；升级/续费仍保持原生禁用。邀请地址 `www.manishare.cn/love/xxxx` 与归属地均是设计示例，不作为真实用户数据或线上地址配置。
- 信息分组：左栏在签名下展示归属地，移除邀请链接与注销行；中栏展示魔晶、粉晶、黄晶及各自图片图标，在学习统计后依次展示注销账号、邀请链接和二维码保存按钮。两栏底部按钮通过 Flex 留白对齐，内容增长时面板自然增高。
- 退出按钮背景仅使用 `TldButton` 的完整品牌渐变层；不在有水平内边距的文字内容层叠加渐变图片，避免内容层与按钮边缘出现两套渐变的色块接缝。按钮继续正常显示，未绑定业务操作。
- 资源：页面私有 `ProfileCompanion` 展示背景、气泡、手写文案和角色图；文案 SVG 是 Figma 原字形，另有完整可访问文本，不依赖本机特殊字体。气泡保留导出阴影边界，角色图不是二维码。SVG 字节不改写，位图仅转为无损 WebP、保留原始尺寸；所有资源静态导入，无临时 Figma URL。资料区明暗主题消费语义颜色及全局图标滤镜，陪伴区保留原稿插画配色。
- 响应式字号：页面标题、字段和值使用全局语义字号阶梯，1920px 保持设计稿字号，较小视口按 H5 / 平板 / 普通 PC 阶梯收紧。
- 扩展：接入真实档案能力时先确认 API、状态和失败反馈；独立用户动作进入 feature，档案 DTO 与领域模型分层，并同步行为测试和本说明。
- 响应式：H5 单列依次呈现个人信息、成长信息和陪伴区；`md` 采用两列资料区，陪伴区在下方居中；`xl` 恢复 575/575/490 三栏比例与至少 952px 面板高度。陪伴区内部按插画区域比例定位，不缩放整页；长字段截断并保留完整 title，布局使用 `min-w-0` 防止溢出。本页沿用设计稿的 24px PC 边距，是三栏资料/插画特殊布局，不套用常规列表页 250px 宽屏边距。
- 验证：`pnpm run format && pnpm run test && pnpm run lint && pnpm run build`；PC 按 Figma 的 1920×1080 基准及较窄桌面视口核对字段顺序、资源位置、三栏比例，确认退出/二维码保存按钮正常显示且不触发业务，升级按钮仍禁用。纯静态组合不新增状态测试；768×1024 平板两列和 390×844 H5 单列的视觉与真机兼容由用户验收。
