# 漫奇联创天使

## 职责

- 还原 Figma 节点 `1096:33618` 的联创天使首发福利、权益、详情容器和底部支付栏。
- 福利、权益和支付保持静态 UI；详情富文本区域留空，不接入支付、会员协议或限量名额接口。背景音乐具备页面内播放控制与提示浮层，曲目当前未配置。

## 公共入口

- `index.ts` 仅导出 `CollaborationPage`。
- 应用路由为 `/collaboration/`，从 AppLayout 侧栏“漫奇联创天使”进入。

## 布局与响应式

- 屏幕宽度从 `1440px` 起，页面固定在顶栏下方的剩余视口；详情区域使用 `min-h-0` 内部滚动，支付栏留在容器底部。
- H5 与小屏平板不固定页面高度，详情随 AppLayout 页面滚动；支付栏使用 `sticky bottom-0` 并保留 Safe Area。
- 内容最大宽度为设计稿的 `1212px`；在 1920px 视口和 200px 侧栏下自然形成约 254px 两侧留白。

## 约束与扩展

- 权益、暂停和支付图标均为该 Figma 节点导出的原始 SVG，存放在 `assets/`。
- 后续接入富文本时，只向现有 `article` 注入已完成安全处理的内容，不改变 PC/移动端滚动边界。

## 背景音乐

- `ui/CollaborationMusicControl.tsx` 替换原静态暂停图标，尺寸及所在布局保持28px；真实播放成功后才展示暂停，其他状态展示播放入口。控制与定位模型留在本页面，不跨模块导入顶栏二维码私有组件，不新增依赖、接口、存储键或Electron能力。
- `model/background-music.ts` 的 `collaborationMusicTracks` 是唯一曲目配置入口，目前为空。空配置不创建Audio、不设置空src、不发起音频请求；进入页面展示“背景音乐暂未配置”，确认以浮层内错误文案反馈，保留取消和手动重开，不伪造播放成功。素材补充后配置可用同源URL；本地音频文件的构建接入及后端列表均在提供素材/协议后另行核对。
- 有曲目时进入页面尝试有声播放，检查play返回结果；被浏览器拦截则提示用户确认，加载失败单独显示可重试错误。确认在点击调用栈内直接调用play，不能先await接口或计时器。播放成功关闭提示，按钮切换播放/暂停；暂停恢复保留当前曲目位置。同一个Audio实例依次播放全部曲目，末尾回到首曲。
- 取消、Escape和点击外部关闭提示，本次进入不再自动重复打开；音乐按钮可手动重新打开。取消正在等待的播放会停止播放器，迟到结果不能改变已取消状态；离页停止音乐、移除事件监听、清除src并释放音频资源，晚到的播放结果同样失效。Strict Mode重挂载可重新初始化。
- 提示采用现有surface-raised主题色和圆角，宽280px、内边距10px、按钮32px高，标题使用text-card-title、辅助说明使用text-label语义字号；PC标题18/26px、说明14/20px，默认内容高110px，配合顶栏附近的按钮向上展开。底部尖角对齐音乐按钮，优先上方、空间不足翻到下方，距视口边缘12px。Portal仅在挂载后创建，避免被页面overflow裁切；正文/按钮可局部滚动，随scroll/resize/ResizeObserver重新定位，关闭清理监听。非模态dialog不锁定整个页面；自动出现不抢焦点，手动打开聚焦确认，取消/Escape及播放成功恢复按钮焦点。短距离淡入尊重reduced-motion。
- 媒体兼容性：浏览器自动播放权限不能假定，也不能由播放偏好代替；当前仅以受控播放器测试成功、NotAllowedError、资源错误和清理，不宣称真实有声播放已验收。素材补充后需在Chrome及iOS/Safari验证自动播放被拦截、确认播放、多曲循环和离页停止，平板/H5真机由用户验收。
