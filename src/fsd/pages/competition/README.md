# 风采大赛页面

- 职责：展示风采大赛暂未开放状态，包括云朵插图、“温馨提示”和“亲爱的小伙伴，功能正在开发中，敬请期待～”。
- 入口：根 `index.ts` 导出 `CompetitionPage`，通过 app 路由装配到 `/competition/`；侧栏入口支持高亮、直接访问和刷新。
- 约束：纯静态展示，不接入报名、作品、比赛榜单、接口或本地存储；页面资源只服务本 slice。装饰插图不重复朗读提示文案。
- 设计：Figma `z7SIwUb9ep0j0ZaEwFrxJl` 节点 `2036:17398`，插图节点 `2307:26268`，原图 imageRef 为 `06ff3672bba0026b61638533e23c1629abfd5221`。使用该原始 PNG，保留透明留白和比例，与首页云朵资源不同。
- 适配：1920×1080、100%缩放时，主内容区为1720×1000；插图200×200，距内容区顶部252px；标题20/28px、500字重，正文18/25px、400字重，标题与正文间隔26px。内容流式居中偏上，H5插图160×160、正文自动换行，平板插图200×200；沿用语义字号与dark/light颜色，不以固定画布缩放。
- 扩展：实际开放比赛功能须单独确认页面、接口及业务规则，再替换此提示页。
- 验证：`pnpm run format && pnpm run test && pnpm run lint && pnpm run build`；路由测试覆盖侧栏目标和路由集合，静态产物校验及Web/Electron运行时冒烟包含本页。PC对照1920×1080并检查1440×900、刷新和侧栏导航；平板/H5视觉及真机待用户验收。
