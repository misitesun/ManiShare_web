# 言灵觉醒

- 章节来源：点击章节时传`onStartPractice(demoId,mode,chapter.id)`；模式窗暂存原章节ID，开始才传递。根入口`isAwakeningPracticeSource`校验课程/章节/演示组合，区分同为句子游戏的第1、4章。ID只来自本页13张本地示例，不当成后台题库ID；app据此生成`sourceChapter`和章节草稿scope，无新增请求或存储。

- 职责：`/awakening/` 静态课程目录，三排独立可切换选项和触底分页；复用 AppLayout 与 TldPaginationStatus。
- 入口：`index.ts` 导出 `AwakeningPage`，由 app router 懒加载；导航配置接通言灵觉醒入口。
- 数据与约束：首屏8项来自 Figma 779:17722，第二页复用8项并使用独立稳定ID，仅演示分页。默认全部课程/最新上架/免费，与设计一致；稿中免费选中时仍有VIP卡片，因此三排仅维护选中展示，不虚构交叉过滤、付费权限或时间排序规则。切换任意组选项重置首屏，重复点击不重置。仅下述音标课程接通详情，其余详情/购买未定义，不添加虚假跳转。
- 资源：封面、作者、热度与丝带均来自设计稿原始导出，归属当前页面，布局使用主题 token。三排复用 `TldSegmentedTabs semantics="filter"` 的动态下划线，仍保持过滤按钮组（`aria-pressed`）语义，不伪造不存在的 tabpanel。
- 响应式：H5单列，平板两列，PC自适应列数；≥1920px 主内容左右250px、最小卡宽290px，1280～1919px左右16px、最小卡宽270px；列表及详情课程封面在PC、平板与H5均统一3:2，使用object-cover等比裁切，保留原图片宽度和其他布局规则。三排选项各自横向滚动，不撑宽页面。遵循主题和 reduced-motion，全部交互有手型光标、焦点与原生键盘行为。
- 课程详情：`AwakeningCoursePage` 对应 `/awakening/courses/[courseId]/`，首张音标课程及其分页演示副本链接到详情；其他卡片不虚构目标，未知 ID 显示返回入口。路由模板、返回路径与练习演示入口由 app 注入。
- 详情布局：固定面包屑，下方课程简介、工具栏与13张章节卡片共同填满剩余高度并内部滚动；H5单列、平板两列、PC自适应列数。复用 TldProgressBar、TldSwitch、TldButton；进度按0/18显示，不采用稿中与数值矛盾的填充比例。收藏与助手仅当前页面状态；“开始学习”通过 app 注入的 `practicePath` 进入 `/practice/` 本地演示选择页，不直接启动正式课程、章节或账号学习会话。重置仍仅提示当前没有可重置记录，不持久化、不伪造学习记录或付费权限。13张章节卡均可进入本地演示，VIP图标与locked数据保留，当前不作为权限拦截；具体边界见下文。
- 详情资源来自 Figma 779:18458，归属本 slice 的 assets/detail；封面复用本 slice 已有资源。
- 扩展：接口契约确认后再补充筛选元数据、服务端分页、loading/error和学习交互；不将模拟记录视为真实业务数据。
- 验证：`model/catalog-state.test.ts` 覆盖默认选中、独立切换、分页上限与重置；运行 test/lint/build。用户负责最终视觉验收，平板/H5和真机兼容待用户验收。

章节练习导航由本地纯模型`getAwakeningPracticeEntry`按展示kind映射目标：句子（第1、4章）、单词（第2章）、音频（第3章）、视频（第5章）、猜词（第9章）、看图学词（第13章）先打开`features/practice-mode-selection`的`PracticeModeDialog`。各类型默认第一项，点击选项只切换预览，取消丢弃临时选择，开始后调用app注入的`onStartPractice(demoId,mode)`。独立指法（第6章）、音标（第7章）及图片/视频/音频/文章阅读器（第8、10、11、12章）直接进入对应演示；音标入口默认音标练习，原演示目录的口语模式仍保留。顶部“开始学习”仍打开总演示目录。

全部章节使用原生按钮、可见焦点与手型光标；只有选择弹窗入口标记`aria-haspopup="dialog"`。VIP标记提供“仅作展示，本地演示可体验”说明，不删除原ID、顺序和locked字段，不假设真实会员权限。页面仅保存当前待选择的入口，关闭卸载弹窗，不持久化模式草稿。`sourceCourse`仅由app白名单解析为返回详情路径；`demo/mode`由练习owner校验，不当作正式题库ID，真实进度/权限未接。相关映射与回归见`course-detail.test.ts`，路径验证在app的`practice-origin.test.ts`。

演示中的自制技术音视频仅验证播放器，不是本课程的音源/视频，不能因此改变课程或章节的资源、权限和学习记录边界。

看图学词在既有12张卡末尾追加为第13张，采用本地语义kind `picture-word`，与kind7纯图片独立；保留原章节ID和顺序。资源来自用户Downloads的`看图学词.png`（18×18）与`Rectangle 346244770.png`（45×41），原样放入assets/detail并分别显示为18×18图标/45×41底图；不按同名SVG复用猜词底色。第13章保留VIP展示并接通独立看图学词模式弹窗，第8章纯图片直接进入阅读器，不定义后台枚举或会员权限。平板/H5继续沿用既有网格，由用户验收视觉与真机。

- 统一封面动效（2026-10-19）：课程封面复用 [TldTiltedCover](../../shared/ui/tld-tilted-cover/README.md)，沿用本页既有槽位、比例和圆角，只让内部图片随鼠标倾斜/轻微放大并显示光泽。原链接、播放入口、选择和角标保持；收藏/作品编辑态停用动效。触屏与减少动态效果保持静态，离开/失焦/滚动/卸载清理；PC交互专项与平板/H5待用户验收边界见公共组件说明。
