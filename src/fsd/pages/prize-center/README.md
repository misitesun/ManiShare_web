# 奖品兑换中心

- 职责：承载奖品兑换中心的页面编排、兑换类型切换、期待空态与兑换记录展示。
- 入口：`index.ts` 仅导出 `PrizeCenterPage`，由 app router 在 `/prize-center/` 路由下加载。
- 当前范围：默认“其他兑换”展示期待插画；“权益兑换”提供兑换码输入与操作入口；“兑换记录”展示四条静态演示记录。内部points ID继续保留，不新增路由、查询参数或存储契约。
- 约束：不发起兑换或记录请求、不把演示记录当作真实用户数据、不推导积分与权益规则；兑换码提交只经 `shared/notification` 说明功能尚未接入。切换只隐藏面板，已输入兑换码不会因切换丢失。
- 组件：复用 `TldSegmentedTabs` 的内容布局、regular字号和spread间距变体。第一项选中采用accent-green，后两项采用brand；两者在dark分别还原三稿的#00BF63和#01F799。组件仍只回传当前视图ID。
- 资源：`assets/prize-banner.png` 来自75:7169的imageRef 964f359ab51e294746a5d0f9931c91a55c24c3bb，object-cover还原FILL裁切；`assets/exchange-expectation.png` 来自2186:24239的imageRef 25c7136d3c68386f10350a609d995422b5273ca2，object-contain展示。整页设计截图不作为业务资源。
- 设计基准：1920×1080 CSS内容视口、100%缩放、dark与展开200px侧栏。标题26/31、700字重；横幅全局(454,155)、1212×328、圆角20；页签文字从(822,540)起、18/25，选中500/其余400、文案边缘间距130，下划线35×3位于y577。期待图200×160位于(965,712)，文字16/22与插画相隔13px。插画组的5px偏移只在基准宽屏应用。
- 表单基准：全局(822,637)、476×226；label18/25；输入431×40位于(845,720)，按钮180×40位于(970,796)、文案16/22。原先负外边距删除，按布局结构产生位置。
- 表格基准：全局(454,600)、1212px宽；表头54px、16/22/500，四行各52px、14/20/400、字距0.01em；五列的文字中心580/820/1060/1300/1540。colgroup为首尾列保留6px外侧空间，单元格内边距补偿，内容中心保持等距240px；tbody向上重叠1px还原稿中y653首行与表头底边的交叠。行底色使用surface-recessed和surface-raised，状态66×24、12/17、status-positive。
- 响应式：H5左右12px，平板与1280–1919px PC左右16px；≥1920px为本次用户确认的254px例外（1212px横幅），其他同类页默认版心不改变。标题22/28→26/31，页签16/22→18/25，间距24→64→130；插画160×128→180×144→200×160。横幅在xl以下以1212:328比例随宽度收缩，避免固定高度裁掉横幅文字；表单不超过可用宽度，页签与760px最小宽度表格均仅在局部横向滚动；浏览器放大自然重排，不反向缩放。
- 扩展：接口接入前确认兑换码、权限和记录能力边界，数据与状态转换留在model；独立业务动作成立后再评估features。
- 验证：`pnpm run format && pnpm run test && pnpm run lint && pnpm run build`；PC核对三Tab计算样式/几何、输入保留、窄窗口和真实浏览器缩放。平板与H5视觉/真机兼容待用户验收。
