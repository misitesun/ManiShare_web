# 外语逆袭秘籍课程详情

- 职责：展示冰雪口语训练营的二级静态详情，包括标题、海报、课程信息、价格、详情/领取页签与固定底部操作栏。
- 入口：`index.ts` 导出 `ForeignLanguageCoursePage`，路由为 `/foreign-language-guide/courses/[courseId]/`；当前仅 `winter-speaking` 有设计数据，其他 ID 展示未提供详情与返回入口。
- 约束：`backPath` 由 app 注入，复用 `TldBackButton` 确定返回目录；页面不依赖目录 page。海报、播放/VIP图标和轮播指示点来自 Figma 节点 `779:2707`，资源留在本 slice。轮播指示点是静态装饰，视频、购买、VIP领取仅提供尚未开放提示，不模拟支付或授权。
- 富文本：详情用静态语义 HTML 排版，保留段落、标题、列表、链接与图片的容器样式；不注入未经处理的 HTML。详情/领取复用 `TldSegmentedTabs` 等分下划线变体，保留灰色底线并使用橡皮位移动画。未来接入后端富文本需在数据边界统一净化 HTML，不直接使用外部 `dangerouslySetInnerHTML`。
- 响应式：主容器占据顶栏以下视口，返回按钮独占顶部固定行；标题位于 `flex-1/min-h-0` 内部滚动区域开头，与海报、课程信息和富文本一起滚动。底部操作栏不参与滚动并预留 Safe Area。详情页仍采用左右12px/16px/宽屏250px留白，目录页已确认的254px例外不自动套用；H5标题、价格区和领取提示可换行，领取内容在内部滚动区域中，不覆盖底栏。
- 领取提示：2026-10-14用户确认Figma `1:3139` 的普通用户状态。默认仍为详情页签，切换领取后展示本地 `assets/claim-locked.png`（设计节点 `2182:24236`）及“VIP可见，升级VIP或直接购买，可解锁领取”。大屏插画200×160px、图文间距16px、提示18/25字号/行高、字重400、字距0.01em、白色60%；H5插画160×128px、提示14/20，md插画180×144px、提示16/22，xl插画200×160px，≥1920px提示18/25。不新增接口或会员判断，侧栏示例徽标不构成授权；购买/VIP按钮继续通知未开放。真实会员/已购授权和可领取内容另行确认。
- 可见性：现有固定返回行和底栏使1920×1080初次领取文字框底部约2px超出内容区。切换领取后仅调整本页内部scrollTop，在可滚动范围内留16px阅读边距；已完整可见时保留滚动位置，不改变键盘焦点或根页面滚动。`model/claim-visibility.test.ts` 覆盖底部裁切、顶部裁切、无需滚动及边界钳制；图文尺寸和间距继续由浏览器验收。
- 就绪与影响图：事实来源为 Figma 与用户标注；新增路由常量及懒加载入口，目录通过注入路径进入详情，壳层前缀匹配继续保持外语逆袭秘籍高亮。复用既有主题/按钮/页签，不新增依赖、存储、语言 key 或 Electron API；无需真实接口加载与支付状态。
- 扩展：其他课程详情、视频源、轮播素材、领取和支付流程待后续确认；不得将其他课程默认显示为冰雪课程。
- 验证：运行 `pnpm run format`、`pnpm run test`、`pnpm run lint`、`pnpm run build`；检查目录入口、直达与返回、页签、未知ID，以及返回行/底栏固定、标题随内容内部滚动。领取提示按1920×1080/100%缩放读取实际图像尺寸、字号、行高、字重、字距和图文间距，再检查窄屏及真实浏览器缩放。PC由Codex核验，平板/H5视觉与真机待用户验收。此处是静态展示，没有新增状态转换算法，布局不写class字符串镜像测试。
