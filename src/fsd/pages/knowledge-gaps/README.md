# 查漏补缺页

- 职责：承载 `/profile/knowledge-gaps/` 六分类静态列表、错题卡片、搜索排序、分类内删除、批量选择和触底分页。
- 入口：`index.ts` 导出 `KnowledgeGapsPage`，由 app router 的 `KnowledgeGapsPageRoute` 装配，页面私有 UI、模型、测试与资源留在本 slice。
- 约束：只实现本地分类展示及列表交互；分类来源、音频和练习业务未接入，不新增接口、路由或存储。页签、开关与进度条使用显式视觉变体，原默认消费者保持不变。
- 设计与确认：2026-10-14 按 Figma `z7SIwUb9ep0j0ZaEwFrxJl` 节点 `1:4504` 改版；用户确认其余五类先显示空态、删除只作用于当前分类，开始练习和音频暂不接入。

## 分类与本地交互

- 六类依次为句子错题本、不熟悉句子、已掌握句子、单词错题本、不熟悉单词、已掌握单词，默认句子错题本。复用 `shared/ui/tld-segmented-tabs` 的 `TldSegmentedTabs` 下划线筛选组，活动文字为 primary、文字宽度横线为 accent-green、无底线；选择语义为按钮组和 `aria-pressed`。
- 现有 20 条静态示例全部归入句子错题本，其余五类显示各自空态。不由错误次数或复习进度推断熟悉/掌握状态，不制造单词示例。
- 分类切换退出批量模式、清空勾选并重置为首屏10条；搜索文本与排序选择保持。重复选择当前分类不重置。分类、删除、勾选与分页仅在页面内存中生效，离开或刷新恢复初始示例，不新增 query、存储、依赖或接口。
- 搜索复用 `TldInput`，按中英文内容过滤当前分类完整集合，搜索后重置首屏。排序复用 `TldSelect`，默认创建日期降序，也可选择错误次数降序；相同值保持原始顺序。过滤、排序都在分页前执行。
- 日期为统一的 `YYYY-MM-DD HH:mm:ss` 静态文案，按字符串比较，不进行时区转换。接真实API后排序须由服务端在分页前执行。
- 全部删除复用 `TldDialog`，打开时捕获分类ID，确认只清空该分类，包括尚未加载和被搜索隐藏的条目；取消不改数据。清空后退出批量选择，切换其他分类再返回仍保持已删除空态。空分类禁用删除和批量选择。
- 批量选择复用 `TldSwitch` 和卡片左侧的 `TldSelection`；支持独立多选，退出批量模式清空勾选，当前分类排序和追加分页不丢失选中ID。
- 开始练习复用 `TldButton`，音频保留已有图标，二者均禁用，未建立真实业务流程。无接口加载/失败状态或请求副作用。

## 主题、响应式与兼容性

- 控件消费语义主题token，字体按用户确认的微软雅黑/苹方/系统回退。字号选择全局body-tight、tab-label-compact和action-label-compact密度变体，不修改既有默认字号值或壳层。新文案中文展示，保留原有i18n。
- 2026-10-14用户要求精确还原后，≥1920px采用设计标注的左右254px，是架构250px默认值的显式例外；不设页面最大宽度，网格按最小380px卡宽自动排布，基准首卡约393.33px（Figma标注393px，Grid产生子像素分配）。1280～1919px仍各16px，保持三列；平板两列、H5单列及既有边距。页签局部横向滚动，不造成整页横向溢出。
- 基准1920×1080/100%缩放：标题30/36、说明与正文16/22、页签16/22和0.01em字距、文案间距36px、横线约81×3；开始练习18/25且500字重。首卡英文位于(471,333)、中文(470,365)、日期(468,412)，轨道y445；工具栏y252、卡片y317，卡高158px和网格间距16px。不同系统字体字形按用户确认回退，不与原特殊字体逐像素比较。
- H5紧凑正文/页签为14/20、md以上16/22，操作为16/22→18/25；标题沿用既有22→26→28→30阶梯。页面缩放由CSS视口自然重排，不检测缩放/DPR反向缩小，平板/H5视觉与真机仍待用户验收。
- PC基准1920×1080，卡片高158px、间距16px；工具栏与列表按新增页签重新排列。静态示例条目数、内容和真实进度继续由数据模型表达，不为匹配设计截图复制九条相同句子或改写进度。
- 页签滚动容器显式 `overflow-y-hidden`；隐藏的文字宽度测量标记不应产生可操作的纵向滚动，PC检查End键后页签文字和指示线仍完整。
- 分类状态为确定性首次渲染；遵守 `docs/compatibility/next-static-runtime.md`，不引入挂载前存储/视口读取、Portal或新浏览器能力。下划线沿用共享动画的测量、清理与 reduced-motion 降级。
- Codex只验收PC；平板/H5视觉、横竖屏和真机兼容待用户验收。

- 扩展：真实分类来源、熟悉/掌握规则、音频和练习须另行确认；接接口时校验 unknown DTO，显式建模 loading/empty/error，分页失败复用当前页请求，不得跳页或额外补字段请求。
- 单元测试：`model/categories.test.ts` 验证数据归属、空分类和分类内清空；`model/list-state.test.ts` 验证切换、勾选、捕获分类删除和过滤；`model/sort.test.ts`、`model/pagination.test.ts` 继续覆盖排序和分页边界。

- PC复测：六类切换、空态与禁用状态、搜索无结果及清空、排序、多选和退出、分页后切换重置、删除取消/确认及返回空态、键盘焦点和可操作控件光标；核对1920×1080布局及较窄PC溢出。生产静态页核对水合、资源加载和无额外请求。
