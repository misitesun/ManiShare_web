# TldImageUpload

- 职责：提供受控的本地图片选择与预览 UI，默认一张，可通过 `maxFiles` 配置多张；新增入口保持加号居中，已有图片右上角提供移除操作。
- 入口：仅从同目录 `index.ts` 导入 `TldImageUpload` 与 Props。
- 约束：只接收并预览浏览器 `File`，过滤非图片文件，负责创建和回收 Object URL；不上传、不压缩、不持久化，也不补充业务接口。
- 扩展：上传状态、服务端地址、尺寸/格式校验和失败反馈应由真实业务契约驱动；任意业务副作用不得下沉到此组件。
- 验证：纯文件集合规则由同目录单元测试覆盖；浏览器核对选择、预览、移除和键盘操作，平板/H5 由用户验收。

- 显式外观：`appearance="outlined"` 使用130×130px、8px圆角、透明底和语义foreground的30%虚线边框，保留18px加号；默认外观的96px→130px、5px圆角及表面色保持。描边加号直接导出自 ManiShare Figma `546:35769`，与原加号文件不相同，仅此变体使用该资源。
- 预览来源：`previewSource`默认`object-url`，保持创建Object URL并在文件变更/卸载时回收；`data-url`用FileReader读取本机图片，在不允许`blob:`的静态生产CSP下供实际截图预览消费，不修改CSP、不产生上传或额外HTTP请求。文件变更/卸载会终止未完成读取并忽略迟到回调；加载中和读取失败均保留原文件的移除入口，失败不伪装为已成功预览。
- 验证补充：`image-previews.test.ts`覆盖乱序完成、清理、过期回调、读取失败及同步异常；`TldImageUpload.test.ts`覆盖描边变体的原生文件选择/禁用/多选和达到上限的添加入口门控。真实FileReader与生产CSP仍由所属业务的PC运行时检查验证。
