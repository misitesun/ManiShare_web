# 鼠标跟随封面

- 职责：为现有图片提供局部鼠标跟随倾斜、轻微放大、柔和阴影和光泽；外层槽位、文案、角标和导航/选择/播放操作仍由调用方拥有。
- 入口：从 `shared/ui/tld-tilted-cover` 导入 `TldTiltedCover`，传入原 `src`、`alt` 与可选 `loading`、`disabled`。容器自行设置宽度、比例和圆角，组件填满槽位并继承圆角；按用户2026-10-19补充要求，外层固定使用overflow-hidden，倾斜/放大只在原图片区域内裁切，保留卡片原有裁切设置。没有 className/style、点击、翻面或额外焦点入口。
- 真实消费者：言灵觉醒列表/详情、外语指南列表/课程详情海报、学习进度、收藏、作品、笔记本课程包列表/详情、PK大厅/匹配页及创建房间课程候选。图像数据和资源继续留在原 owner，不增加请求、存储或依赖。
- 动效：参考 React Bits [Tilted Card](https://reactbits.dev/components/tilted-card)，按本项目密集课程布局使用最大±8°、1.035倍、800px透视。CSS负责150ms跟随、300ms复位与光泽/阴影，原生Pointer事件仅按稳定槽位计算CSS变量，每帧提交最后一次位置，无React逐帧状态和常驻动画循环。
- 约束：仅鼠标且有精确悬停设备、系统未启用减少动态效果时生效；触控/笔输入保持静态，不拦截滚动和点击，不捕获指针。收藏/作品编辑态通过disabled停用，原选择覆盖层保持。离开、取消、窗口失焦、滚动/调整窗口、文档可见性或系统动态偏好变化时复位；卸载/换图/停用取消待执行帧、移除监听并屏蔽迟到回调。全局窗口监听只在当前封面活动期间注册。
- 主题与适配：布局完全沿用调用方的mobile-first槽位和比例。`cover-glare`与`shadow-tilted-cover`在全局样式提供完整dark/light值；CSS另有motion-reduce静态分支，首次SSR不读浏览器状态。
- 扩展：新增课程封面直接复用本组件；修改统一幅度、帧调度、输入条件或主题值时，同步本说明、相邻测试、样式说明及能力地图。不要复制事件逻辑到页面，也不要将课程资源移入shared。
- 验证：`cover-tilt.test.ts`覆盖中心/四角方向、钳制、非法尺寸、帧合并、布局更新、取消/卸载及迟到回调；组件静态测试覆盖原链接语义、装饰图和SSR。运行 `pnpm run format && pnpm run test && pnpm run lint && pnpm run build`；生产专项 `scripts/tilted-cover-runtime-smoke.cjs`覆盖各入口、真实鼠标、点击/选择、双主题、PC布局和动态偏好。PC视觉以1440×900及1920×1080/100%为基准，平板/H5视觉和真机待用户验收。
