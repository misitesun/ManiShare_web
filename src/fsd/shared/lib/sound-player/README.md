# 短音效播放

## 职责与入口

- 职责：提供一个按需创建的HTMLAudio单通道；不持有业务音色、偏好或课程状态。入口为`createSoundPlayer`和`SoundAudio`等类型，业务只能通过本目录根入口导入。

## 约束

- `play({src,volume,onPhase})`在调用栈内发出真实play请求；不在预渲染、挂载或恢复设置时创建音频。仅真实play成功才回报playing，拒播区分blocked，失败不冒称成功。
- 默认结束／停止后释放源；打字消费者可显式启用retainSource，最多保留一个媒体元素和源，同源从头播放，换源／dispose释放。不会为每次击键重新加载同一个文件。
- 重播、停止、换源和卸载均取消旧监听并递增代次，迟到Promise不影响新声音。通道优先级、限流、开关及音色选择由业务所有者负责；不提供网络请求、后台恢复自动补播或麦克风能力。

## 扩展

目前真实消费者为练习反馈和学习设置试听。新增消费者复用根入口，自己持有通道优先级、限流与播放意图；新增播放策略必须保留事件反馈、过期任务隔离及释放语义，不在本模块增加业务音色、后台自动补播或录音职责。

## 验证

就近单测覆盖重复播放、拒播、过期回调与释放，通过`pnpm run test`执行。实际Web／Electron播放还需验证媒体事件、自动播放拒绝及停止清理；H5真机试听由用户验收，不能从模拟Audio测试推导。各轮实际执行结果见[联合检查记录](../../../../../docs/checkpoints/2026-10-22-practice-games-validation.md)。
