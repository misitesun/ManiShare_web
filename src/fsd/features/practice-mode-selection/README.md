# 练习模式选择

## 职责与公共入口

课程详情选择练习方式、练习内切换模式共用一套插画选择流程。模块只维护打开期间的选择草稿，不加载题库、不判题、不控制练习会话、不写入学习记录。

公共入口为 `index.ts`，导出 `PracticeModeDialog`、`PracticeModeDialogProps`、`practiceModeSelections`、`PracticeModeSelection`、`PracticeModeOption`、`PracticeSelectionMode`、`SelectablePracticeFamily`、`isSelectablePracticeFamily` 和 `isPracticeSelectionMode`。`WordPracticeModeDialog` 已由通用入口替代，原单词目录保留内部复用，不重复维护六项配置。

六个选择族共33项，顺序就是首次打开的显示顺序，默认选中各族第一项：

- 单词 `word`：单词拼读 `pronounce`、单词拼写 `spell`、单词默写 `dictate`、句中练义 `meaning`、指法练习 `typing`、口语评测 `oral`，共6项。
- 句子 `sentence`、音频 `audio`：沉浸听力 `listen`、阅读 `read`、理解自查 `check`、中译英 `translate`、选词拼块 `blocks`、指法练习 `typing`、口语评测 `oral`，各7项。句子阅读按用户确认改称“阅读全览”，音频仍保留当前“阅读全浏”，本轮不改其他任务名称。
- 视频 `video`：沉浸听力、理解自查、中译英、选词拼块、指法练习、口语评测，共6项；不推定存在阅读项。
- 猜词 `guess`：猜词模式 `guess`、阅读模式 `read`、打词模式 `spell`，共3项。这里的 `spell` 是猜词打词，不借用单词拼写的名称和插图。
- 看图学词 `picture`：沉浸听力、中译英、指法练习、口语评测，共4项；与纯图片内容独立。

“阅读全浏”为历史原稿用字，句子项已按2026-10-21用户确认改为“阅读全览”，仅覆写该族显示文案，不改变其他消费者或模式ID。模式白名单按族校验，不因为同一ID存在于其他族就允许进入当前族。

## 交互状态与约束

调用方持有 `family`、`open`，可提供 `initialMode` 与 `onStart(mode)`。每次打开以族内有效的 `initialMode` 初始化临时选择，缺省或跨族输入回退首项；点击选项只换插图和名称预览。点击“开始练习”先调用 `onOpenChange(false)`，再调用 `onStart(mode)`，由调用方执行导航或会话切换。

取消、关闭、Escape和遮罩只关闭弹窗，不调用 `onStart`。关闭卸载内部草稿，再次打开重新初始化；不记忆取消的选择、不写本机存储。弹窗已打开时 `initialMode` 变化不覆盖正在选择的草稿；切换 `family` 会重新初始化。练习内取消保留题号和输入、确认同模式保持会话、确认其他模式重置本轮状态，由练习页面负责，本模块不越权处理。

FSD约束：依赖共享 `TldDialog`、`TldButton` 和本地模式目录，不导入 `pages`、路由或题库。页面只通过根公共入口组合本功能，路径回调由app装配。当前只启动已标明的本地演示，无题库接口、真实判题、真实录音评分和练习全局按键逻辑。原生按钮操作与Dialog的Escape关闭属于基础控件行为。

## 扩展与验证

练习页通过`TldDialogMotionProvider`启用与其他练习弹窗一致的进退场。`PracticeModeDialog`持续挂载受控外壳，每次open重新从当前模式初始化；关闭时保留待选画面用于退场，取消不提交。开始先关闭，`onAfterClose`完成后仅提交一次待选模式，避免切会话key提前卸载动画。课程详情未装配动画作用域，继续即时关闭/开始；不因练习页修正改变课程设计几何或默认交互。嵌套设置子窗沿共享焦点隔离，不在本模块复制动画或全局监听。

扩展新的选择族或小模式时，同时更新目录、族内白名单、素材来源、页面入口映射与测试；不能仅凭通用插画目录推定权限、题库或模式全集。模式选择和练习题面是不同验收范围，本模块设计还原不代表各小模式题面已完成后续精确稿。

同目录测试覆盖族内白名单、跨族拒绝、默认首项、原始单词配置复用、插图映射差异、猜词专属插图，以及预览/开始/取消分离和SSR不读浏览器。新增目录4项单元测试已通过。根任务统一运行全量测试、lint、构建及生产运行时冒烟；实际开关、草稿丢弃、焦点恢复、1920px计算样式/几何、PC缩放和所有章节导航的最终结果记录于 [练习页开发文档](../../../../docs/practice-page-development.md)，不以静态class断言代替视觉验收。
