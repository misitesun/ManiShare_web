# 口语评测

全模式可复用的四阶段口语评测展示能力。首个消费者为 `pages/practice` 的单词拼写模式。本轮录音、评分和回放全部模拟，不访问麦克风、MediaRecorder、Web Audio、WebSocket 或评分接口，不保存录音与成绩。

## 公共入口与装配

只通过本目录 `index.ts` 导入 `OralAssessmentDialog`、`useOralAssessmentDemo` 及目标／结果／控制器契约。

- 页面负责入口的业务可用性、当前题目和轮次 ID、浮层状态、V 键、暂停及切题；拼写答对且“显示口语评测”开启才展示入口。
- 点击入口或按 V 打开准备态；再次点击麦克风或按 V 开始模拟录音，再次操作结束录音。评测中禁止重复提交，1200ms 后显示固定样例结果。
- 结果展示逐词分数、总分圆环、准确度／流畅度／完整度、等级及评语；点击重新录制或按 V 直接重录。播放按钮切换模拟播放状态，并按本次显示时长自动结束，不产生回放音频。
- `target` 包含 `id`、`text`、`translation` 与 `kind`（单词／句子／音标），不依赖练习页领域类型。关闭、目标 ID／文本变化、轮次变化会取消任务并复位；暂停保留阶段，冻结计时和评分；播放在暂停后停止。
- 页面通过 `wave: ReactNode` 注入 `LearningAudioWave` 和录音／朗读动画偏好，通过 `onFeedback` 注入已有录音开始音、评分等级音。本 feature 不横向依赖 `learning-settings`。
- 新功能只接入单词拼写。其他模式继续使用原演示面板，后续可通过相同目标与控制器契约逐个迁移。

## 设计、主题和适配

Figma 四态节点：`2450:6907`、`2450:7017`、`2450:7131`、`2450:7241`。1920×1080 CSS 视口、100% 缩放下，弹窗宽1220、高641、左350、上225、圆角12；准备态单词40/56、译文24/34、麦克风100×100。结果卡439×240，重录／播放图标60×60。图标原样导出，出处见 `assets/README.md`。

复用 `shared/ui/tld-dialog` 的 Portal、渐变边框／底色、进入退出动效、焦点锁、关闭按钮、Esc 及滚动管理。正文与按钮移动端流式重排，结果卡小屏变为单列，长词／长句可换行，短视口使用弹窗内部滚动；不固定画布缩放、不改根字号。颜色使用主题 token；`oral-action` 是原稿录音操作提示绿色，dark/light 均完整定义。

圆形图标统一使用内部 `OralAssessmentActionIcon`：默认只显示 PNG 中心圆和图标，外两圈不显示；录音中或模拟回放中，两个独立圆层以1.8秒周期、0.9秒错相向外扩散并淡出，中心图标不缩放、不闪烁。待录音、评测中、结果闲置以及暂停状态保持静态。原100／60px占位不变；`oral-record`／`oral-play` 取原 PNG 中心绿／蓝，dark/light 保留图形原色。GSAP 只经共享入口，局部作用域、状态变更／卸载清理；不可见、后台或 reduced-motion 时停用扩散。设置声纹继续独立工作。

## 状态与扩展边界

`oral-assessment-demo.ts` 是不依赖浏览器的单一状态所有者，支持时钟注入；React Hook 在挂载后配置并订阅快照，首屏固定准备态。定时任务有代次校验，关闭、重录、切题或卸载后，旧回调不能复活结果或发出完成音。

样例总分40、准确度30、流畅度40、完整度50，不根据按键、时长或随机数推算发音成绩；逐词内容随目标文本变化。当前无真实录音错误态、授权弹窗或上传逻辑。后续真实录音／评分应替换模拟控制器，并单独实现权限、格式探测、网络取消与资源释放，不能把当前模拟状态视作浏览器录音兼容已验收。

指定哇学社源码的启动／结束／结果及浏览器处理记录见 [源码审阅与本轮范围](../../../../docs/practice-oral-assessment-development.md)。
