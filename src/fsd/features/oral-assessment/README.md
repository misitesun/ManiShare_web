## 公共入口与装配

2026-10-21句中练义复用：打词填空仅正确后、句中辩义在目标词已展示时，按“显示口语评测”设置开放入口与V。评测当前目标词，目标ID包含玩法，切换玩法／题目取消旧评分及模拟播放；点击和快捷键由页面同一门控拥有。本次只新增消费者，不改变本feature媒体行为，未运行测试或构建，见[句中练义记录](../../../../docs/practice-word-meaning-development.md)。

只通过本目录 `index.ts` 导入 `OralAssessmentDialog`、`OralAssessmentContent`、`useOralAssessmentDemo` 及目标／结果／控制器契约。`OralAssessmentContent` 是唯一四态正文，`presentation='dialog' | 'page'` 只区分布局；不创建 Portal、焦点锁或独立计时任务。`OralAssessmentDialog` 继续拥有 TldDialog 外壳与关闭行为，页面模式直接组合正文。

- 页面负责入口的业务可用性、当前题目和轮次 ID、浮层状态、V 键、暂停及切题；拼写／默写答对且“显示口语评测”开启才展示入口，句子沉浸听力不要求答题，沿该设置与非空目标门控。目标 ID 包含内容族、模式、题目与重练轮次。
- 点击入口或按 V 打开准备态；再次点击麦克风或按 V 开始模拟录音，再次操作结束录音。评测中禁止重复提交，1200ms 后显示固定样例结果。
- 结果展示逐词分数、总分圆环、准确度／流畅度／完整度、等级及评语；点击重新录制或按 V 直接重录。注入`playback`时，播放按钮请求真实示例音频，`playing`仅跟随媒体事件，等待／失败不启动动画，点击可取消等待或停止播放；没有注入时，仍按模拟显示时长结束。
- `target` 包含 `id`、`text`、`translation` 与 `kind`（单词／句子／音标），不依赖练习页领域类型。关闭、目标 ID／文本变化、轮次变化会取消任务并复位；暂停保留阶段，冻结计时和评分；播放在暂停后停止。
- 页面通过 `wave: ReactNode` 注入 `LearningAudioWave` 和录音／朗读动画偏好，通过 `onFeedback` 注入已有录音开始音、评分等级音。本 feature 不横向依赖 `learning-settings`。
- 单词拼写、单词默写、句中练义与句子沉浸听力共用该入口及控制器；听力传完整句子及`kind='sentence'`，准备态采用现有句子字号和换行。其他模式继续使用原演示面板，后续可通过相同目标与控制器契约逐个迁移。本次复用不增加接口请求、麦克风采集或持久化。

## 状态与扩展边界

`oral-assessment-demo.ts` 是不依赖浏览器的单一状态所有者，支持时钟注入；React Hook 在挂载后配置并订阅快照，首屏固定准备态。定时任务有代次校验，关闭、重录、切题或卸载后，旧回调不能复活结果或发出完成音。

默认样例仍为总分40、准确度30、流畅度40、完整度50，不根据按键、时长或随机数推算发音成绩；逐词内容随目标文本变化。可选`sampleScores`注入固定总分序列，按完成评测次数循环，普通重渲染不改序列位置；重置、关闭和切题复位，取消的评分不推进。三项指标来自四档固定样例，独立于总分，不定义正式评分公式。当前无真实录音错误态、授权弹窗或上传逻辑。后续真实录音／评分应替换模拟控制器，并单独实现权限、格式探测、网络取消与资源释放，不能把当前模拟状态视作浏览器录音兼容已验收。

## 2026-10-22 示例音频回放接线

此前`replay()`只设置`playing`并按模拟录音时长启动定时器，所以可见声纹却无声音。现新增可选公共`OralAssessmentPlayback`端口（status、play、stop），由练习页注入`usePracticeReading`，feature不创建Audio、不横向导入页面或设置能力。加载／等待提示音为pending，真正playing才驱动扩散与声纹；ended／pause／error复位，不按录音时长结束真实播放。按钮在等待时可取消，失败时提示重试。`replayAudio/replayPending/replayError`描述播放展示，不构成第二套媒体状态。

页面／弹窗同一接线：题目原有`readingSource`优先，单词缺项仅匹配页面已拥有的十个WAV。回放前暂停题面朗读，录音开始暂停两类朗读；暂停、重录、关闭、切题与卸载停止当前播放和前置等待。宿主订阅自然结束并按visit隔离旧媒体，结束只停止回放、不自动切题；未注入端口的固定演示保持原行为。状态回归用例覆盖等待、playing、结束、失败重试、撤销、暂停及换题，不把`play()`完成当作播放结束。

本轮只做定向格式化、音源格式／帧数／路径结构和静态差异核对，未运行测试、lint、类型检查、build、开发服务器或实际音频播放。PC／H5／平板／Electron音质、权限和顺序待用户验收，未提交或推送Git。
