# 创建 PK 房间

- 职责：独立的创建房间用户动作，包含对战、难度、游戏类型、课程单选、章节多选、模式、两组书写方式和主题配置；以有效配置回调调用方，不持有大厅生命周期。
- 入口：根 `index.ts` 导出 `CreateRoomDialog`、`RoomCreation`、`RoomCourseOption`、`RoomChapterOption`。当前消费者为 `pages/pk-arena`，传入页面所属模拟目录；不导入其他 feature/page 私有模块。
- 契约与约束：组件挂载即打开；`onClose` 由调用方卸载组件，草稿随卸载丢弃，下次挂载恢复默认。`onCreate` 只提交合法配置，调用方完成本地创建并卸载弹窗。当前同步本地动作，不伪造接口、异步加载、机器人或匹配。
- 配置：默认真人/困难/句子/首个课程前两句子章/中译英默写/默认背景。难度保留独立选择，仅人机配置使用；中译英和听写书写选择独立保存。选词拼块仅句子可选，提交的 writing 为 null；切换单词自动回中译英。改课程或题型清空章节；同项重选不清空。至少一个合法章节才能创建，拒绝不存在课程、章节及跨题型章节。
- 展示：课程首排4项、章节首排3项，“更多”展开同一目录中的剩余模拟候选，折叠不取消选择。权限标记只展示，候选章节均可选，真实会员限制等待产品/接口契约确认；现稿仅默认与闪电两种背景，不新增未设计主题。
- 复用与影响图：pages/pk-arena → features/pk-create-room → shared/ui/tld-dialog、tld-selection、tld-button、tld-membership-badge。公共弹窗新增 extra-large 802px、居中标题和自定义 footer；业务按钮通过底部插槽复用 TldButton。现有弹窗继续使用原尺寸和默认操作区，需回归已有消费者。
- 主题与适配：Figma `1097:52429`，弹窗组 `1097:53152`，1920×1080中802×972；全量使用语义 token 和字号。H5课程两列、章节单列，md课程四列、章节三列；标题和底部固定，正文内部滚动，12/24px视口边距。PC人工视觉验收，平板/H5视觉与真机待用户验收。
- 课程封面：所有端的课程候选图片统一3:2，保留已有卡片宽度、文字区、权限标记及课程单选覆盖层；图片使用object-cover等比裁切且显式h-auto覆盖原始尺寸属性，其他配置和交互保持现状。
- 兼容性：遵守 Next 静态预渲染确定性，Portal在挂载后初始化；复用焦点限制、Escape/遮罩关闭、滚动锁定和焦点恢复，无存储键、路由、依赖、主题 token 或 Electron bridge 变更。
- 扩展：真实创建接口先确认课程题型、章节权限、默认配置和房间契约，外部 DTO 校验后映射；等待/对战流程另行交付，不能把模拟目录作为真实学习规则。
- 验证：同目录测试覆盖默认、空态、跨课程/题型清理、多选幂等、拼块限制、书写独立和有效配置；运行 format/test/lint/typecheck/双环境build/runtime:smoke，PC检查深浅主题、更多、关闭重开、无章节禁用、内部滚动和键盘行为。
