# 本地每日签到

- 职责：模拟每日签到动作、累计次数、校验及不可关闭的打卡窗；由首页编排定位和俱乐部提示。用户于2026-10-14确认本地模拟范围，不接学习时长阈值、签到或积分接口。
- 入口：根index导出DailyCheckinDialog、CheckinRecord以及记录读写/状态转换函数。
- 约束：累计初始3天，上海自然日每天一次有效操作加1；累计不受1000目标限制，进度轨道使用共享标准化截断。日期经shared/lib/time，记录经shared/lib/storage，version1、日期及安全整数先校验，损坏记录恢复示例；保存失败保持弹窗并显示可重试信息。
- 布局：Figma2120:20365的563×212窗；原始云朵图1254×1254展示120×120，光晕75px/blur20px；20px/34px累计文字与24px数字、14px/20px按钮。3/1000实际填充0.3%，稿中20px填充与数值不一致，已在确认方案约定以数值为准。H5上下重排，md恢复横向布局；不使用缩放画布。
- 扩展：真实签到接入须确认身份、时区、初始累计、接口幂等与学习阈值，当前本地记录不代表账号服务器状态，不关联其他首页模拟统计。
- 验证：checkin.test覆盖同日去重、次日、越目标和存储校验；runtime:smoke覆盖不可关闭、焦点、刷新/永久关闭和PC几何。运行format/test/lint/build及生产冒烟，PC1920×1080/1440×900深浅主题人工验收，平板/H5视觉及触摸真机待用户验收。
