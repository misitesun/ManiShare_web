# i18n 基础设施

- 职责：初始化 i18next，保留已有中文/英文资源与语言切换能力，为后续重新开启多语言提供统一边界。
- 入口：`index.ts` 导出初始化副作用、语言配置与 `useAppLanguage`。
- 约束：当前版本的新页面和新功能默认直接展示中文，不要为新文案新增语言 key 或占位英文。已有 i18n 资源和消费者继续保留；普通页面任务不主动删除、重写或扩充它们。
- 扩展：只有产品需求明确重新开启多语言时，才为新增 key 同步目标语言资源，并评估当前中文字面量的迁移范围；不以共享短词替代完整业务句子。
- 验证：已有资源仍由 `locales/locales.test.ts` 检查现存 key 一致性；运行 `pnpm run test && pnpm run lint && pnpm run build`。
