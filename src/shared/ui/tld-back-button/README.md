# TLD 返回按钮

- 职责：统一页面返回入口的箭头、按钮外观、字号、悬停与焦点，使用 Link 保留真实导航语义。
- 入口：从 `src/shared/ui/tld-back-button` 导入 `TldBackButton` 和 Props，必传 `to`，可选 `label`（默认“返回”）。
- 约束：返回目标由页面/路由装配提供；不猜测浏览历史，不使用 `navigate(-1)`，直接打开二级页时也能返回确定父页。查询参数由调用方提供。不开放 className，位置由外层布局控制。箭头使用 Figma 导出资源，颜色适配沿用壳层图标主题滤镜。
- 扩展：其他页面需要返回入口时复用本组件；有业务取消或未保存确认时由业务层处理，不能把业务状态放入共享按钮。
- 验证：同目录测试覆盖目的路径、查询参数和自定义文案；运行 test/lint/build。视觉及设备验收按任务约定交由用户。
