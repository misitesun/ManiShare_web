# TldImageUpload

- 职责：提供受控的本地图片选择与预览 UI，默认一张，可通过 `maxFiles` 配置多张；新增入口保持加号居中，已有图片右上角提供移除操作。
- 入口：仅从同目录 `index.ts` 导入 `TldImageUpload` 与 Props。
- 约束：只接收并预览浏览器 `File`，过滤非图片文件，负责创建和回收 Object URL；不上传、不压缩、不持久化，也不补充业务接口。
- 扩展：上传状态、服务端地址、尺寸/格式校验和失败反馈应由真实业务契约驱动；任意业务副作用不得下沉到此组件。
- 验证：纯文件集合规则由同目录单元测试覆盖；浏览器核对选择、预览、移除和键盘操作，平板/H5 由用户验收。
