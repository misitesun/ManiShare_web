# 共享笔记区

- 职责：为笔记本一级列表、课程包二级页和章节笔记页统一展示笔记组、记录行、静态添加/编辑入口，以及组/记录的本地删除确认。
- 入口：根 `index.ts` 导出 `NotebookNotes`；调用方传入 `groups`。一级页拥有分页，二级页拥有课程包筛选与页签。
- 约束：不拥有路由、课程封面、分页或服务端数据；删除使用 `TldDialog`，确认前不改数据，取消不删除。移除仅保留在当前组件实例，卸载后恢复 fixture；切换课程需通过稳定课程 key 重建实例。添加和编辑继续保留已有静态入口，实际表单不在本次范围。
- 扩展：两个真实页面消费者出现后从 pages/notebook 提升至此，原页面不得保留实现副本或兼容重导出。未来真实新增/编辑/删除流程可下沉为 feature；外部请求状态由确认的契约驱动。
- 验证：`model/notebook-deletion.test.ts` 覆盖目标隔离和幂等；运行 test/lint/build。检查删除取消、删除确认、删除最后一组后的空态和键盘操作。
