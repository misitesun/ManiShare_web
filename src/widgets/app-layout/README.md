# 应用布局

- 子导航默认收起：首次加载或刷新时，“玩家档案”不展开子菜单，点击后切换展开/收起；当前子路由仍正常高亮父导航，不自动展开。此状态仅在组件内保存，不持久化。

- 顶部搜索复用 `shared/ui/tld-input` 的 large 尺寸与尾部提交按钮，悬停/聚焦为绿色边框；保持原有表单提交、查询参数和搜索路由。H5 仍仅显示搜索图标；PC/平板保持原来的宽度约束。

- 顶栏“建议反馈”通过显式 `action="feedback"` 打开 `features/submit-feedback` 弹窗；其余未实现入口继续保持静态按钮。弹窗只维护本地草稿和图片预览，当前不请求反馈或上传接口。

- 侧栏特殊入口：“漫奇联创天使”当前没有路由，按普通静态项展示，不默认使用选中渐变；后续接入真实页面后只由路由激活状态控制高亮。“风采大赛”和“奖品兑换中心”使用各自的 24×24 图标并遵循普通静态项的主题滤镜。无路由的展示项不添加指针光标或虚假点击行为。

- 职责：提供 H5 覆盖式抽屉、平板/PC/Electron 可在 200px 侧栏与 64px 图标轨道间切换的导航、80px 桌面顶栏、当前路由标题、全局课程搜索入口、统一会员标签、底部钻石路由入口、主题/语言入口和页面 `Outlet`。
- 入口：`index.ts` 导出 `AppLayout` 及导航、子导航、底部导航、标签配置类型；app 层通过 props 注入导航数据、底部钻石入口、标签数据和搜索路径。已有多语言导航使用 `labelKey` / `pageLabelKey`，中文优先的新页面可通过 `label` / `pageLabel` 直接注入文案。
- 约束：widget 不反向导入 `app`，不承载课程请求或学习业务状态。PC 顶栏标题仅从 app 注入的当前有效导航项推导，直接文案优先于翻译键，平板/H5 隐藏以保留搜索空间；页面纵向滚动由固定视口高度的内容列统一承载并隐藏轨道，确保侧栏、顶栏和宽屏内容基线稳定。顶栏小管家形象从 `shared/constants` 获取，与业务页面共用同一资源；未实现导航只展示不可用文案，标签第一版是无业务动作按钮。侧栏由同一开关状态驱动跨端过渡：PC 默认展开，平板默认显示 64px 图标轨道，二者展开时占据 200px 布局列、收起时保留头像和导航/功能图标；头像信息区开合时始终保留 98px 最小高度和 22px 顶部基线，学习时长徽标使用独立绝对定位层且不参与普通文档流，防止右侧文字或时长徽标显隐时下方导航与头像跳动。PC/平板收起时必须先隐藏用户信息、导航文案和二级导航，头像与导航图标在宽度动画全程保持左侧基线，再压缩到 64px 轨道中央；展开时先完成宽度动画再显示文案，避免窄宽度内文字重排或图标横向闪动。H5 抽屉宽度固定为视口宽度的 50%，收起后完全离场，展开时固定覆盖内容且不得推动主布局。图标轨道隐藏文案和二级导航，通过 `shared/ui/tooltip` 在 hover/focus 时向右展示对应文字，点击带子导航的图标先展开侧栏。断点变化恢复对应端的默认开合状态。Tailwind v4 的 `translate-x-*` 使用独立 `translate` 属性，抽屉自定义 transition 必须显式包含 `translate`，不能只写 `transform`。抽屉与子导航动画必须保留 Escape、焦点恢复、完全关闭后不可聚焦和 reduced-motion 直接结果。
- 动画与交互细节：导航项与高亮背景始终保持 `w-full`，跟随侧栏可用宽度连续收缩；不得在收起状态立即切成固定 40px，以免高亮态瞬间跳变。所有实际可点击的导航链接、开关、搜索和功能按钮显式使用 `cursor-pointer`，不可用的展示项不伪装为可点击。小于 768px 时顶栏隐藏搜索输入框，将搜索收为带边框的图标按钮；768～1279px 时搜索框占顶栏可用宽度的一半且不超过 468px，不再填满右侧功能入口之前的剩余空间；右侧功能入口始终保留边框和完整点击区域。超宽屏下顶栏功能标签展示文案时必须使用内容最小宽度，不能被平板的固定图标宽度压缩而互相重叠。
- 字号：展开导航、二级导航、用户信息、搜索和宽屏标签使用全局响应式语义字号；图标轨道 Tooltip 与学习时长徽标保持所属组件的紧凑规格。
- 头像区几何：展开和收起均固定为 98px 高，42px 头像始终位于左侧 11px、顶部 22px。右侧资料独立绝对定位，昵称单行省略并提供完整 title，等级不拆行、会员徽章整体换行；资料显隐和换行均不参与头像区高度计算，下方导航起点保持一致。
- 底部钻石入口：由 app 注入唯一的 `AppFooterNavigationItem`，当前指向 `/branch-company`；激活态参与顶栏标题和边框反馈，侧栏收起时沿用 Tooltip，不在 widget 内反向读取路由配置。
- 扩展：新增导航、标签或真实路由在 `app/config` 完成；顶栏动作通过受限的 `AppUtilityAction` 显式登记，不使用文案判断行为；跨页面完整展示区块建立独立 widget，页面私有视觉留在 page slice。
- 验证：`model/navigation-state.test.ts` 覆盖断点默认开合和开关状态转换；运行 `pnpm run test && pnpm run lint && pnpm run build`。Codex 在 PC 端人工检查搜索跳转、侧栏收起、子导航过渡与无横向溢出，本设计以 1920×1080 为视觉基准并可补充 1440×900 PC 适配；390×844 H5 与 768×1024 平板的抽屉、Escape/遮罩关闭、视觉和真机兼容由用户验收。
