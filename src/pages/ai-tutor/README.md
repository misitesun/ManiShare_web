# AI 助教

- 导师卡片与聊天场景均复用 `TldMovingHighlight`，以 data-highlight-key 标记测量目标；保留 TldSelection 原生 radio 和勾选标记。ResizeObserver 跟随真实网格尺寸更新位置，不使用固定索引位移；新增文案或场景不需要维护高亮坐标。

- 场景滑块层级：列表建立 isolate 层叠上下文；默认/hover 背景为 z-0，移动高亮为 z-10，图片和文字为 z-20。按钮自身不建立 z-index 上下文，避免背景随整个按钮压到滑块上；高亮保留 pointer-events-none。

- 职责：Figma `779:9855` 的导师和场景选择静态页面；入口 `index.ts` 导出 `AiTutorPage`。
- 约束：所有目录数据和设计资源归本页所有，不调用接口、不补全数据、不申请麦克风权限。聊天内容为设计稿静态示例；设置、播放、示范、发送和录音仅提示暂未接入，不伪造 AI 回复。
- 交互：导师默认 Sarah；场景默认未选，开始对话在未选场景时禁用。两组原生单选复用 TldSelection，CTA 复用 TldButton。开始对话进入 app 注入的聊天路径；切换导师返回明确父页并通过 mentor/scene 查询参数恢复选择。非法聊天参数显示返回入口。
- 二级入口：`AiTutorChatPage` 对应 `/ai-tutor/mentors/:mentorId/scenes/:sceneId`，Figma `1097:45723`。场景切换 replace 当前路径，不堆积浏览历史。默认文字输入，右侧图标切换语音态，切换保留草稿。设置图标打开 Figma `1097:46100` 对话框，外壳、开关和单选分别复用 `TldDialog`、`TldSwitch` 与 `TldSelection`；盲听、翻译、语速、阶级与反馈均为当前页本地预览状态，不持久化、不调用接口。
- 对话布局：响应用户一屏要求，以 dvh 减壳层顶栏约束高度；导师栏、输入区固定，消息内部滚动。md 起场景纵向独立滚动，H5 场景横向滚动；选中框采用排行榜同款 200ms 位移动效，支持 reduced-motion。沿用 PC 内容边距，卡片高度随视口伸展，不照搬设计稿底部空白。
- 布局：手机一列、md 两列、xl 四列；图片按 291:200 保持比例。1920px 起沿用应用 250px 内容边距，内容自然滚动，兼容黑白主题。
- 资源：assets 的页面图片来自对应 Figma 设计稿，不使用远端运行时图片请求；设置控件使用共享 UI，不保留页面专用开关或单选 SVG。导师名称与口音文案按设计稿保留。
