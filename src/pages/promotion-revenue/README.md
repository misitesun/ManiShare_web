# 推广收益页面

- 职责：承载推广链接、收益概览、可提现信息、佣金、提现和注册明细的静态分页展示。
- 入口：根目录 `index.ts` 仅导出 `PromotionRevenuePage`，由 `/promotion/revenue` 路由懒加载。
- 约束：当前统计值、邀请信息、佣金和注册记录均为页面私有静态演示数据，不代表真实结算规则；复制、提现以及真实数据请求尚未接入。
- 页签边界：佣金、提现和注册明细复用 `TldSegmentedTabs` 等分下划线变体，横线位移时保留灰色底线；佣金和注册明细使用页面私有静态分页列表，提现记录复用 `widgets/withdrawal-records`，与分公司提现明细保持同一数据和交互契约。
- 提现交互：共享提现区块负责收款码弹窗、审核说明 Tooltip 和静态分页，页面不得保留实现副本。
- 响应式：H5 默认纵向排列，平板扩展统计网格，PC 在宽屏下对齐 1920px 设计稿；表格窄屏时局部横向滚动。
- 主题与文案：只使用全局语义主题 token；当前中文直接展示，不新增 i18n key。
- 扩展：接入真实收益接口时，在本 slice 建立数据模型和加载状态；复制文本仍需通过 `shared/lib/clipboard`，用户通知通过 `shared/notification`。
- 验证：运行 `pnpm run test && pnpm run lint && pnpm run build`；PC 按设计稿检查三类明细表，及提现记录的收款码弹窗和审核说明 Tooltip，平板/H5 由用户验收。
