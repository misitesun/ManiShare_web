# 玩家档案页

- 职责：承载 `/profile` 玩家资料静态页面，展示个人信息、会员与学习摘要，以及设计稿要求的第三列空内容占位。
- 入口：`index.ts` 导出 `ProfilePage`，仅由 app router 懒加载。
- 约束：页面当前只呈现设计数据；复制、编辑、绑定、升级、注销和退出按钮均不接业务行为；退出登录复用共享 `TldButton`，但不在静态页中虚构会话退出流程。页面私有 UI 与 Figma 导出资源留在本 slice，SVG 原始字节不改写，明暗主题通过语义颜色和全局图标滤镜适配。
- 响应式字号：页面标题、字段和值使用全局语义字号阶梯，1920px 保持设计稿字号，较小视口按 H5 / 平板 / 普通 PC 阶梯收紧。
- 扩展：接入真实档案能力时先确认 API、状态和失败反馈；独立用户动作进入 feature，档案 DTO 与领域模型分层，并同步行为测试和本说明。
- 验证：`pnpm run test && pnpm run lint && pnpm run build`；PC 按 Figma 的 1920×1080 基准验收三列与 575/575/490 面板比例，768×1024 平板两列和 390×844 H5 单列的视觉与真机兼容由用户验收。
