# 笔记本页

- 职责：承载 `/profile/notes` 静态笔记本页面，按 Figma 展示“全部笔记”和“按课程包”两种列表，并复用共享分段页签与触底分页状态。
- 入口：`index.ts` 导出 `NotebookPage`，仅由 app router 懒加载。
- 约束：当前数据为页面私有静态演示数据；每个列表首屏分别展示 3 个句子组与 12 个课程包，触底追加第二页。删除组或记录必须先使用共享 `TldDialog` 二次确认，确认后仅从当前本地静态视图移除；新增、编辑和课程包进入行为仍未确认。按用户要求，本页文案只维护中文，不新增 i18n key。页面私有操作图标保存在本 slice，跨笔记本与作品页复用的 Figma 课程封面从 `entities/course-package` 获取。
- 扩展：接入接口时先以 `unknown` 校验 DTO，再由页面或独立 feature 驱动 `idle/loading/exhausted/error`；接入服务端删除时保留当前确认流程，并补充提交中、成功和失败反馈。确认新增、编辑或课程包导航行为后再建立对应业务边界与行为测试。
- 响应式：≥1920px 时以侧栏右侧主内容区为基准左右各留 250px，取消版心最大宽度；笔记组保持整行伸展，课程包按最小 290px 卡宽自动排布列数。1280～1919px 不设版心最大宽度，左右统一各 16px，既有列数不变；同一视口和侧栏状态下与其余四页内容边界对齐；平板/H5 边距不变。
- 字号：页签、笔记标题、记录正文、课程卡标题和操作标签使用全局响应式语义字号，1920px 保持设计稿上限。
- 验证：`model/pagination.test.ts` 覆盖分页状态转换，`model/notebook-deletion.test.ts` 覆盖本地删除状态；运行 `pnpm run test && pnpm run lint && pnpm run build`。PC 在 1920×1080 及超宽屏核对 250px 边距、笔记组高度、自适应课程卡与删除确认弹窗；768×1024 平板与 390×844 H5 的视觉及真机兼容由用户验收。
