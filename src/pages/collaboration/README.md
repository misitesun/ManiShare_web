# 漫奇联创天使

## 职责

- 还原 Figma 节点 `1096:33618` 的联创天使首发福利、权益、详情容器和底部支付栏。
- 当前只提供静态 UI；详情富文本区域留空，不接入支付、会员协议或限量名额接口。

## 公共入口

- `index.ts` 仅导出 `CollaborationPage`。
- 应用路由为 `/collaboration`，从 AppLayout 侧栏“漫奇联创天使”进入。

## 布局与响应式

- 屏幕宽度从 `1440px` 起，页面固定在顶栏下方的剩余视口；详情区域使用 `min-h-0` 内部滚动，支付栏留在容器底部。
- H5 与小屏平板不固定页面高度，详情随 AppLayout 页面滚动；支付栏使用 `sticky bottom-0` 并保留 Safe Area。
- 内容最大宽度为设计稿的 `1212px`；在 1920px 视口和 200px 侧栏下自然形成约 254px 两侧留白。

## 约束与扩展

- 权益、暂停和支付图标均为该 Figma 节点导出的原始 SVG，存放在 `assets/`。
- 后续接入富文本时，只向现有 `article` 注入已完成安全处理的内容，不改变 PC/移动端滚动边界。

## 验证

- `pnpm run test`
- `pnpm run lint`
- `pnpm run build`
- Codex 仅对 1920×1080 PC 端对照设计稿；平板和 H5 的视觉与真机验收由用户完成。
