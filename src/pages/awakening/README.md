# 言灵觉醒

- 职责：`/awakening` 静态课程目录，三排独立可切换选项和触底分页；复用 AppLayout 与 TldPaginationStatus。
- 入口：`index.ts` 导出 `AwakeningPage`，由 app router 懒加载；导航配置接通言灵觉醒入口。
- 数据与约束：首屏8项来自 Figma 779:17722，第二页复用8项并使用独立稳定ID，仅演示分页。默认全部课程/最新上架/免费，与设计一致；稿中免费选中时仍有VIP卡片，因此三排仅维护选中展示，不虚构交叉过滤、付费权限或时间排序规则。切换任意组选项重置首屏，重复点击不重置。仅下述音标课程接通详情，其余详情/购买未定义，不添加虚假跳转。
- 资源：封面、作者、热度与丝带均来自设计稿原始导出，归属当前页面，布局使用主题 token。三排复用 `TldSegmentedTabs semantics="filter"` 的动态下划线，仍保持过滤按钮组（`aria-pressed`）语义，不伪造不存在的 tabpanel。
- 响应式：H5单列，平板两列，PC自适应列数；≥1920px 主内容左右250px、最小卡宽290px，1280～1919px左右16px、最小卡宽270px；卡面比例291:186，三排选项各自横向滚动，不撑宽页面。遵循主题和 reduced-motion，全部交互有手型光标、焦点与原生键盘行为。
- 课程详情：`AwakeningCoursePage` 对应 `/awakening/courses/:courseId`，首张音标课程及其分页演示副本链接到详情；其他卡片不虚构目标，未知 ID 显示返回入口。路由模板与返回路径由 app 注入。
- 详情布局：固定面包屑，下方课程简介、工具栏与12张章节卡片共同填满剩余高度并内部滚动；H5单列、平板两列、PC自适应列数。复用 TldProgressBar、TldSwitch、TldButton；进度按0/18显示，不采用稿中与数值矛盾的填充比例。收藏与助手仅当前页面状态，学习/重置仅提示未开放，不持久化、不伪造学习记录或付费权限。章节类型、VIP标记均为静态演示。
- 详情资源来自 Figma 779:18458，归属本 slice 的 assets/detail；封面复用本 slice 已有资源。
- 扩展：接口契约确认后再补充筛选元数据、服务端分页、loading/error和学习交互；不将模拟记录视为真实业务数据。
- 验证：`model/catalog-state.test.ts` 覆盖默认选中、独立切换、分页上限与重置；运行 test/lint/build。用户负责最终视觉验收，平板/H5和真机兼容待用户验收。
