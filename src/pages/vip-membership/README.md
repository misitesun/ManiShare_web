# 畅学 VIP 页面

- 职责：承载 `/vip` 的畅学 VIP 静态方案展示，包括会员分类栏、黄金/终身方案、联创天使引导面板、免费体验方案、购买周期选择和购买/续费文案适配。
- 入口：仅从根目录 `index.ts` 导出 `VipMembershipPage`、页面 Props 与用户会员状态类型。
- 约束：联创天使面板的富文本区域当前留空，仅提供跳转现有联创天使页面的入口；支付、免费体验领取、分享和真实会员请求仍不在当前范围，页面资源不得提升到全局目录。
- 数据边界：当前不发起请求；会员价格与权益来自 Figma 节点 `1097:43216`，免费体验内容来自节点 `1097:43886`。设计稿只提供一组黄金 VIP 价格，因此周期切换当前只切换选中态，不伪造其他周期价格；体验人数与时长按设计稿静态展示，不启动前端计时器。
- 用户状态：`viewer.activeProductIds` 是后续接口适配点；默认空数组，展示“立即购买”，包含对应产品 ID 时展示“立即续费”。
- 交互：页面默认展示畅学 VIP；会员分类栏在畅学 VIP、漫奇联创天使与免费体验面板间受控切换。免费体验的续费、分享链接、会员购买/续费和客服入口通过统一通知明确反馈，不模拟成功业务结果。联创天使“去看看”使用 app 注入的路径跳转 `/collaboration`，页面不反向导入 app 路由配置。
- 响应式：H5 默认单列，`xl` 起使用设计稿的 470px 双卡布局；页面主内容保持居中，卡片内部在窄屏自然换行。
- 扩展：联创天使富文本、免费体验领取和分享能力等待后续接口任务；真实价格接口接入前不得用前端推算补齐周/月/季价格。
- 验证：运行 `pnpm run test && pnpm run lint && pnpm run build`；PC 对照 1920px 设计稿，平板与 H5 的视觉及真机兼容由用户验收。
