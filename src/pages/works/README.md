# 我的作品页

- 职责：承载 `/profile/works` 静态作品管理页面，按 Figma 展示共享状态页签、响应式作品卡网格、浏览/编辑状态、多选删除和触底分页。
- 入口：`index.ts` 导出 `WorksPage`，仅由 app router 懒加载。
- 约束：当前数据为页面私有静态演示数据；首屏使用设计稿 8 个作品，默认为无选择入口的浏览态，点击“编辑”后整张卡片可多选，同时显示“取消”和“删除”；取消只清空本次选择，确认删除后回到浏览态。触底追加同一组静态续页。共享/不共享仅切换当前静态管理视图，不虚构服务端筛选或共享接口。作品选择和确认删除只改变当前内存视图，删除前必须使用共享 `TldDialog`；课程包摘要和封面从 `entities/course-package` 获取。页面文案按当前要求只维护中文。
- 扩展：接入作品接口时先以 `unknown` 校验 DTO，再补齐 loading/empty/error、真实分页、共享状态修改及删除提交反馈；服务端行为确认前不建立 API 或持久化边界。
- 响应式：≥1920px 时以侧栏右侧主内容区为基准左右各留 250px，取消版心最大宽度，网格按最小 290px 卡宽自动排布列数；1280～1919px 不设版心最大宽度，左右统一各 16px，既有列数不变；同一视口和侧栏状态下与其余四页内容边界对齐；平板/H5 边距不变。
- 字号：页签、编辑操作、共享状态、卡片标题、分类和笔记数量使用全局响应式语义字号，1920px 保持设计稿上限。
- 验证：`model/pagination.test.ts` 覆盖分页状态转换，共用 `features/edit-course-collection` 测试覆盖编辑、多选、取消与本地删除；运行 `pnpm run test && pnpm run lint && pnpm run build`。PC 在 1920×1080 及超宽屏核对 250px 边距、自动列数、282px 卡高、行间距和删除确认弹窗；768×1024 平板与 390×844 H5 的视觉及真机兼容由用户验收。
