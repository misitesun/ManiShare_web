# 学习进度页

- 职责：承载 `/profile/learning-progress` 静态学习进度页面，按 Figma 展示课程分类页签、章节摘要、线性进度与课程列表，并沿用笔记本页面的触底分页模式。
- 入口：`index.ts` 导出 `LearningProgressPage`，仅由 app router 懒加载。
- 约束：当前仅有“全部”和“言灵觉醒”分类的页面私有静态演示数据，其他分类明确展示空状态；首屏展示 Figma 的 3 条课程进度，触底追加演示页。删除必须先使用共享 `TldDialog` 二次确认，确认后仅从当前本地静态视图移除。课程进度由已练习章节与总章节计算，文案直接使用中文，不新增 i18n key；Figma 封面与删除图标保存在本 slice 的 `assets/`。
- 扩展：接入接口时先以 `unknown` 校验 DTO，再将课程数据、分类分页与删除提交拆入真实业务边界，并补齐 loading、empty、error、重试及提交反馈；后端明确各课程类型数据前不虚构其他分类内容。
- 响应式：≥1920px 时以侧栏右侧主内容区为基准左右各留 250px，取消版心最大宽度，学习进度卡保持整行伸展；1280～1919px 不设版心最大宽度，左右统一各 16px，既有列数不变；同一视口和侧栏状态下与其余四页内容边界对齐；平板/H5 边距不变。
- 字号：页签、课程标题、说明、章节摘要和进度文字使用全局响应式语义字号，1920px 保持设计稿上限。
- 验证：`model/pagination.test.ts` 覆盖分页状态转换，`model/learning-progress-deletion.test.ts` 覆盖本地删除状态；运行 `pnpm run test && pnpm run lint && pnpm run build`。PC 在 1920×1080 及超宽屏核对 250px 边距、690px 分类页签、250px 课程卡、章节摘要、进度条和删除确认弹窗；768×1024 平板与 390×844 H5 的视觉及真机兼容由用户验收。
