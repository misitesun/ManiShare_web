# 奖品兑换中心

- 职责：承载奖品兑换中心的页面编排、兑换类型切换、静态缺省状态与兑换记录展示。
- 入口：`index.ts` 仅导出 `PrizeCenterPage`，由 app router 在 `/prize-center` 路由下懒加载。
- 当前范围：默认展示“积分兑换”的设计稿缺省态；“权益兑换”提供静态兑换码输入与操作入口；“兑换记录”按设计稿展示四条静态演示记录。
- 约束：不发起请求、不把静态记录当作真实用户数据，不伪造兑换操作成功，不在页面中推导积分、权益或兑换规则；兑换码提交只经 `shared/notification` 说明功能尚未接入。
- 组件：兑换类型复用 `TldSegmentedTabs` 的固定宽度动态下划线，页面只持有当前视图状态，不再维护私有页签实现。
- 响应式：H5 左右留白 12px，平板与 1280–1919px PC 留白 16px，≥1920px 按 mainPage 契约使用 250px 左右留白；内容区流式适配，不使用整页缩放，兑换记录表在窄屏中局部横向滚动。
- 扩展：接入接口前先确认积分、权益和记录的能力边界，数据与状态转换移入 `model`；出现独立用户操作时再评估 `features`。
- 验证：`pnpm run test && pnpm run lint && pnpm run build`；PC 按 1920×1080 对照设计稿，平板与 H5 由用户验收。
