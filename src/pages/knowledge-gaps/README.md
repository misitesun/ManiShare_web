# 查漏补缺页

- 职责：承载 `/profile/knowledge-gaps` 静态列表页，按设计稿展示错题卡片、筛选控件、批量选择入口、复习进度和触底分页。
- 入口：`index.ts` 导出 `KnowledgeGapsPage`，仅由 app router 懒加载。
- 约束：当前未确认搜索、排序、删除、批量选择、音频和练习业务，相关控件只展示且无动作；开始练习复用共享 `TldButton`，但不在静态页中虚构练习流程。设计卡片与分页演示数据、Hook、内部组件和 Figma 原始 SVG 留在本 slice。首屏 10 条与 Figma 一致，触底后追加第二页静态数据；已加载分页的条目必须进入同一个响应式网格，不得按页创建独立 Grid 导致未满行断层；真实 API 的 loading/error 由共享分页状态组件支持，但本静态页不会伪造请求失败。
- 扩展：接入接口时以 `unknown` 校验 DTO，并由页面或未来独立 feature 显式驱动 `idle/loading/exhausted/error`；失败重试必须复用当前页请求，不得跳页。确认音频、筛选、删除或开始练习行为后再建立对应业务边界与测试。
- 响应式：≥1920px 时以侧栏右侧主内容区为基准左右各留 250px，取消版心最大宽度，网格按最小 380px 卡宽自动排布列数；1280～1919px 不设版心最大宽度，左右统一各 16px，既有列数不变；同一视口和侧栏状态下与其余四页内容边界对齐；平板/H5 边距不变。
- 字号：页面标题、说明、筛选、卡片正文和状态标签使用全局响应式语义字号，1920px 保持设计稿上限。
- 验证：`model/pagination.test.ts` 覆盖分页状态转换；运行 `pnpm run test && pnpm run lint && pnpm run build`。PC 在 1920×1080 及超宽屏核对 250px 边距、158px 卡高与自动列数，并确认追加第二页后从上一页未满行继续排列；768×1024 平板两列及 390×844 H5 单列的视觉与真机兼容由用户验收。
