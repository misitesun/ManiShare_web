# 查漏补缺页

## 本地交互

- 搜索复用 `TldInput`，按中英文内容过滤完整静态集合，搜索后重置首屏；排序、过滤均在分页前执行。
- 全部删除复用 `TldDialog`；取消不改数据，确认清空包含未加载分页的全部条目，并退出批量选择。仅作用于当前页面内存，刷新可恢复，不调用后端。
- 批量选择复用 `TldSwitch`，每条卡片左侧居中显示 `TldSelection`。圆形按钮可独立勾选多项，语义为 checkbox；退出批量模式清空选中，排序/分页不丢失选中ID。开始练习及音频仍未接入。
- 控件使用现有主题色，输入聚焦有 brand 边框与淡阴影；菜单和选择栏支持显隐过渡、inert 隔离隐藏焦点、reduced-motion。无新增依赖、路由或存储。
- 测试：`model/list-state.test.ts` 覆盖选中、退出、清空、过滤；共享控件同目录渲染契约测试。PC交互验收，平板/H5待用户视觉与真机验收。

- 职责：承载 `/profile/knowledge-gaps` 静态列表页，按设计稿展示错题卡片、筛选控件、批量选择入口、复习进度和触底分页。
- 入口：`index.ts` 导出 `KnowledgeGapsPage`，仅由 app router 懒加载。
- 约束：搜索、删除和批量选择为本地静态交互；音频和练习未接入；开始练习复用共享 `TldButton`。排序入口复用 `shared/ui/tld-select`，默认创建日期降序，也可切换错误次数降序；相同值保持原始顺序。全部静态条目先排序再分页，改变排序重置首屏10条，触底追加，重复选择不重置。日期为统一的 `YYYY-MM-DD HH:mm:ss` 格式，按字符串比较，不进行时区转换；接真实API后排序须由服务端在分页前执行。页面保留原始静态日期，目前日期相同，因此默认顺序不变。设计卡片、数据和分页Hook留在本slice，同一个网格承载全部已加载条目。
- 扩展：接入接口时以 `unknown` 校验 DTO，并由页面或未来独立 feature 显式驱动 `idle/loading/exhausted/error`；失败重试必须复用当前页请求，不得跳页。确认音频、筛选、删除或开始练习行为后再建立对应业务边界与测试。
- 响应式：≥1920px 时以侧栏右侧主内容区为基准左右各留 250px，取消版心最大宽度，网格按最小 380px 卡宽自动排布列数；1280～1919px 不设版心最大宽度，左右统一各 16px，既有列数不变；同一视口和侧栏状态下与其余四页内容边界对齐；平板/H5 边距不变。
- 字号：页面标题、说明、筛选、卡片正文和状态标签使用全局响应式语义字号，1920px 保持设计稿上限。
- 验证：`model/pagination.test.ts` 覆盖分页状态转换；运行 `pnpm run test && pnpm run lint && pnpm run build`。PC 在 1920×1080 及超宽屏核对 250px 边距、158px 卡高与自动列数，并确认追加第二页后从上一页未满行继续排列；768×1024 平板两列及 390×844 H5 单列的视觉与真机兼容由用户验收。
