## 1. 全局约定

- **Enter 推进当前主流程**：输入提交、揭晓、继续 / 下一题，以及口语当前阶段的主动作。
- **空格服务当前内容**：文本输入空格或合法词槽导航，听力 / 媒体播停，阅读原生滚动，已结束题态的下一题备用键。
- **V 服务口语**：文本输入时仍输入字母 v；非编辑作用域且附加口语入口可用时打开评测。口语作用域内按阶段录音或重录。
- **Esc 管理当前层级**：优先关闭最上层浮层；没有浮层时打开暂停 / 退出提示。口语权限准备或评测中可取消本轮操作。
- **Tab / Shift+Tab 保留原生焦点导航**；方向键按当前作用域处理，普通编辑区保留光标 / 词槽导航，练习面板采用↓展开、↑收起；无修饰方向键不用于切题。作答输入内的Ctrl / Meta + A、C、X、V、Z、Y（含Shift组合）保留全选、剪贴及撤销 / 重做；仅Shift+字符（包括大写字母，且无Ctrl / Alt / Meta）保留原生输入，不执行练习动作。普通编辑器继续保留原生编辑；这类Shift+字符绑定仅在允许的非编辑作用域执行，作答Enter及显式切题仍按既定作用域规则处理。
- **朗读 / 掌握 / 不熟读取设置**：默认 Shift + L / Shift + J / Shift + K，合法用户配置优先；不支持该能力时不执行，也不显示可用提示。
- **手动切题与自定义快捷键同动作**：底栏两端“上一题 / 下一题”是点击入口；默认Shift+←上一题、Shift+→下一题，合法用户配置优先。点击与按键共用切题入口；未完成可直接跳过，每次实际切题后题内状态重置，返回已完成或未完成题目都重新开始。设置字段与统一运行逻辑已接入。
- **答案 / 音标详情独立显隐**：↓从页面顶部向下展开当前模式对应的答案或音标详情面板，↑收起；仅改变面板显隐，不重置输入或改写答题结果。
- 模式、阶段和布局分别管理；左右与上下布局、响应式重排不改变同一模式 / 阶段的动作。所有模式保留可点击 / 触摸入口，操作不依赖物理键盘。

### 1.1 统一输入与指法键盘映射

- **输入来源**：PC 使用实体键盘；平板、H5 使用系统软键盘，平板接入实体键盘后同样正常输入。原生输入控件统一接收文本变更，再将可确定的字符或按键信息映射到自定义键盘；不能仅依赖物理 `keydown` 获取软键盘字符，也不因 UA、视口宽度或设备分类禁用外接键盘。不增加输入方式切换设置。
- **目标展示职责（待素材补齐）**：各端均保留彩色自定义键盘和半透明手部示意，键帽、文字、手按同一几何关系随容器局部等比适配，保持五行；键帽不承担点击 / 触摸录入。页面正文和工具栏按正常响应式规则重排，不随键盘整体缩放。布局和图层细节见[开发文档第 6.6 节](practice-page-development.md#66-指法键盘彩色键帽半透明手与特殊键)。
- **映射职责**：当前应输入字符对应的目标键 / 手指提示，与实体键盘或系统软键盘实际输入产生的反馈分别管理。软键盘只能提供已提交文本时，依据文本变更反馈可确定的字符，不伪造物理按键、修饰键或 CapsLock 状态；IME 合成期间不将候选文本作为最终输入。大小写、空格、标点提示与既定判题规则分别管理。
- **范围边界**：以上为后续统一实现契约，不改变本文 Enter / 空格 / V 的阶段动作或快捷口语门控。当前原生输入可编辑，指法只保留几何槽位及大小写/空格/标点等手动演示状态；独立彩色键帽和手层素材仍缺。统一输入事件归一化与目标/实际输入高亮映射继续暂缓；本轮仅接入练习命令按键和动作派发，不能将静态演示选择当作实时映射完成。

### 2.3 手动切题与自定义切题绑定（2026-10-16确认）

- 点击底栏左端“上一题”执行`question.previous`，点击右端“下一题”执行`question.next`；它们是手动操作按钮。
- 默认Shift+←执行上一题，Shift+→执行下一题；合法用户自定义优先，分别与点击执行同一个动作。首末项边界、题态处理、媒体与异步任务清理均由同一切题入口决定，不能按点击或键盘来源维护两套规则。
- 中间“切题”区域展示当前有效的用户键位提示，默认显示Shift+←/→，修改后随设置回显。左右端按钮中的箭头只表达方向，不要求用户使用裸方向键。
- 未完成也可直接上一题 / 下一题。每次实际切题后题内临时状态恢复初始值，包括输入、题态、词块排列及口语临时流程；回看已完成或未完成题目均不恢复之前的作答状态。旧媒体、录音 / 评测及异步回调按清理边界取消；答案 / 详情显隐重新初始化。游戏 / 小模式的设置缓存继续保留，不随题内重置清空。
- Enter仍先解析当前主流程：输入时提交，结果时可解析为同一个`question.next`。自定义切题动作与当前主流程的绑定分别管理，绑定冲突按第5节处理。
- 动作关系、默认键位、自定义能力与题内重置规则均已确认；切题偏好字段与运行逻辑已接入，精确默认值与用户覆盖共用绑定来源。

- 五项全局偏好继续使用原`english-learning-preferences-v1`键。在挂载恢复时，对旧绑定中存在的Ctrl修饰键执行一次迁移：将Ctrl替换为Shift，保留主键和其余修饰键，按统一顺序整理并去重Shift。例如Ctrl+A/M/Q分别转为Shift+A/M/Q，Ctrl+Alt+Shift+K转为Alt+Shift+K。无Ctrl的有效选择不因迁移重置，旧缓存缺字段仍补对应默认。
- Shift数字 / 标点组合采用标准英文字符对的基础键身份：Ctrl+1、Ctrl+;迁移后保持Shift+1、Shift+;，实际`event.key`为`!`、`:`时仍执行对应动作。已有Shift+!等价于Shift+1，录入、有效绑定、运行时匹配与冲突校验使用同一规范；字母保持用户选择，不按物理`code`猜测其他布局。
- 迁移结果回写原v1偏好，不新增练习快捷键存储键；不得在预渲染读写Storage。迁移及保存由学习设置owner经共享存储入口处理，页面只读取有效绑定。转换后与其他绑定或保留流程键冲突时，保留转换结果、可见提示并停用冲突项，不改成默认值冒充迁移成功。
- 输入保护优先：作答输入内Ctrl / Meta+A/C/X/V/Z/Y（含Shift组合）继续全选、复制、剪切、粘贴、撤销和重做；仅Shift按下、无Ctrl / Alt / Meta且`event.key.length === 1`的字符（包括大写字母）保留原生输入，不触发练习快捷键；Enter和方向键不属于单字符，继续按既定作用域处理。普通草稿 / 笔记等编辑区继续保留原生编辑。这类Shift+字符绑定只在允许的非编辑作用域触发；作答Enter及显式切题仍遵守原有作用域规则，不能以“统一Ctrl改Shift”为由拦截系统编辑组合。
- 本节覆盖早先Ctrl默认和不允许Shift+字母的活动约定；第8节原稿键位和开发文档既有验收历史保留来源，不作为本轮迁移已验收的证据。本轮实现与实际验证记录由开发文档最新修正节维护。

输入阶段的空格具体是字符还是词槽导航，由题目明确的输入形态决定，二者不会同次执行；是否接受某个空格属于输入 / 判题契约，不由绑定层猜测。空格不作为文字作答的通用提交键。

答错阶段保留可编辑输入，不因 Enter 自动切题；自动显示答案阈值和正式错误计数另行接入。揭晓不记为答对。指法“完成”依据该模式已确定的完成状态，不能在本文档中据任意字符数创造正式完成算法。

### 3.4 会话和完成浮层

- 普通题面 Esc：没有更高浮层时打开暂停 / 退出提示；已有浮层时只由最上层处理。
- 完成弹窗：空格再练一次，Enter 下一章，Esc 返回。提示和解析统一读取`practice-bindings`的`session.replay/nextChapter/return`；Esc由最上层`TldDialog`关闭链处理。当前本地演示无下一章，按钮禁用并显示“暂无可用下一章”，Enter只反馈、不透传或误开同一章。再练/返回/关闭均在退场完成后重置或返回演示目录，退场期间继续阻断背景命令。题数来自当前列表，今日时长暂无聚合来源时显示“—”，不等同于左上角本轮计时。
- 暂停、退出确认、笔记、草稿、设置、报错等浮层：保留可见按钮与原生焦点交互，Esc 关闭允许关闭的最上层；不在编辑区套用底层 Enter / 空格 / V。
- 返回位置、真实保存、末章和权限结果仍见开发文档，不因绑定已确定而宣称业务服务完成。

## 4. 快捷口语入口与设置门控

设置可见名称统一为 **“显示快捷口语评测入口”**，沿用现有 `showEvaluation` 字段、默认 true、保存格式与历史值。此文案涵盖答后、听力、阅读等附加入口，不新增另一开关。

**当前实现**：`pages/practice/model/practice-visibility.ts` 的 `canShowQuickOral` 已供可点击 UI 使用，按内容族、模式、题态、目标和开关判断；纯阅读器与独立口语不另挂快捷入口，独立口语 UI 不因该开关关闭而失效。V监听已按同一门控接入；口语阶段仅演示，真实采集 / 评分仍按后续业务契约接入。

快捷入口可用需同时满足：

1. `showEvaluation` 开启。
2. 当前内容 / 子模式支持评测，且有明确的当前评测目标。
3. 当前题态允许，评测目标已经可以展示；不能借 V 提前泄露答案。
4. 当前没有阻断题面操作的更高浮层，且不处于普通文本输入作用域。

阶段规则以第 3 节为准：单词拼写 / 默写仅答对后开放；理解自查、猜词需揭晓后；中译英与选词拼块可在揭晓 / 答对后开放；单词拼读不提供；沉浸听力、音标及阅读在目标已经展示且可确定时开放；纯音视频、纯图片、纯文字不提供。

关闭开关时，附加入口隐藏且其 V 不派发，不能只隐藏图标仍保留快捷键。开启只意味着入口可见 / 可操作，不自动开窗、不自动录音。直接选择的独立口语模式不受此开关影响，口语作用域内录音键继续可用。

打开快捷口语后暂停自动切题和冲突的题目发音；结束、关闭、Esc 均回到原题，不因返回顺带下一题。不强制重启被暂停的自动播放；具体真实媒体恢复顺序在后续接入时统一确定。快捷评测期间底层题目不得继续消耗本次 Enter / 空格 / V。

## 5. 作用域、冲突与事件边界

1. 先确定最上层活动作用域，再解析动作：浮层 / 口语优先于底层题目。草稿、笔记、报错、设置搜索等编辑区保留文本与原生控件行为。
2. 聚焦按钮、链接、选择控件及词块时，Enter / 空格先按该控件语义执行；控件已消费则不再次执行题目动作。词块选择不由全局空格监听再补一次。
3. 题目输入区明确声明自己是作答输入：Enter 可提交，空格 / V 仍按其输入规则处理；仅Shift+字符（包括大写字母，且无Ctrl / Alt / Meta）保留原生输入，Ctrl / Meta+A/C/X/V/Z/Y（含Shift组合）保留原生编辑。普通多行编辑器的 Enter 仍换行。不可用“所有 input 都忽略”遗漏答题输入，也不可用全局监听劫持其他编辑器。
4. 屏蔽 IME 组词与候选确认，忽略长按 repeat；一次按下只执行一个动作，阶段切换后需松开再按。不能同次提交、切题，或开窗后立刻录音。
5. 精确匹配修饰键，忽略无关组合；默认 Enter / 空格 / V / Esc 为无修饰键。V 表示字母键，大小写归一，不能把文本输入或带其他修饰键的组合当入口。
6. 仅在实际消费事件时阻止默认行为；保留 Tab 导航、阅读空格滚动、输入字符和必要原生按钮激活，不用全局 `preventDefault` 阻断页面。
7. 只有活动练习界面可以派发练习动作；卸载、切题、切模式、暂停或退出时同步取消旧定时任务、发音与评测 run，防止旧回调切换新题。
8. 可配置动作按当前模式能力过滤。例如音频 / 视频无掌握、不熟时，Shift + J/K 或用户保存组合均不触发对应动作。
9. 当前练习默认值已改为Shift，Ctrl组合不再作为练习绑定。Shift、Alt、Meta及功能键仍需按真实宿主验证；renderer收发成功不能替代浏览器 / 系统保留键验收，不通过额外全局拦截抢占宿主快捷键。

## 6. 集中实现与统一替换方式

以下约束已由页面私有命令、绑定、底栏和受控口语模块落实：

- 练习 page owner 内集中定义一份“默认绑定 + 现有用户偏好覆盖”，以第 2 节动作标识连接模式 / 阶段解析器；仅有真实跨页面消费者时再评估下沉公共能力。
- 模式只声明支持的动作、输入形态与阶段差异，不在各组件散写 `Enter`、空格或 `KeyV` 监听；界面按钮、提示和实体键盘都调用同一动作入口。
- 先由作用域、内容类型、子模式、题态、口语状态和设置解析可用动作，再由绑定来源生成提示。禁用动作不显示可用快捷提示。
- 将来更换默认按键只修改集中绑定；改变某模式语义只修改该模式的阶段映射。同步本文和实际行为测试，避免逐个页面替换文字造成提示 / 行为漂移。
- 现有 `playShortcut`、`masteredShortcut`、`unfamiliarShortcut` 继续走原校验和存储；旧值按第2.5节进行Ctrl→Shift迁移，保留主键及其余修饰键；不借迁移重置为默认值。上一题 / 下一题配置已由同一偏好所有者管理，包含旧数据兼容、冲突校验与持久化，不另建按模式复制的快捷键缓存。
- 流程键与用户配置冲突时集中校验并可见反馈，不能靠组件监听顺序或隐式抢键决定赢家；冲突值保留供用户修改，暂不注册对应快捷键。
- 静态 UI 获准实施相应按键时，只派发本地演示动作；正式课程发音调度、判题、真实录音、评分和业务保存待对应 P1 契约，不能通过按键文档偷偷接入服务。

## 7. 实现验收清单

- 指法未完成 Enter 不跳题，完成后按约定确认 / 下一题；纯按键题不出现口语入口。
- 指法由实体 / 系统软键盘经同一原生输入通道进入处理，再分别更新目标提示与实际输入反馈；PC、平板、H5 均显示示意键盘，平板外接键盘可用，无输入方式切换项，示意键帽不点击录入。软键盘输入不依赖 `keydown`，无法确定的物理状态不伪造。
- 快捷口语首次 V 只开窗，再次按键开始；录音中一次按键停止，评测中不重入；结果 Enter 返回原题、空格回放、V 重录。
- 独立口语结果 Enter 下一题；关闭快捷入口开关不禁用独立模式，但附加入口和对应 V 一起禁用。
- 聚焦控件、普通编辑区、最上浮层和题目按优先级处理；一次 Enter / 空格 / Esc 不触发两层动作。
- 完成弹窗只执行再练 / 下一章 / 返回；末章和无权限分支不误跳；切题 / 退出后旧任务不修改新题。
- 更换一处集中绑定后，各模式提示与实际动作同步；五项用户自定义快捷键按迁移规则保留主键及其余修饰键；转换冲突可见停用。
- 手动上一题 / 下一题与对应自定义快捷键执行相同动作；可用性、边界、状态处理和清理结果一致；修改切题设置后底栏提示同步。
- 默认Shift+←/→分别切上一题 / 下一题，用户自定义优先；未完成可跳过，切回已完成 / 未完成题目均重置题内临时状态，游戏 / 小模式设置缓存保持。
- 答案与音标详情按↓从顶部向下展开、↑收起，点击与键盘共用显隐动作；收起面板不清输入、不改答题结果、不切题；方向键不透传到其他作用域。
- 看图学词沉浸听力 / 中译英 / 口语评测提供掌握与不熟，指法练习不提供；按钮与用户键位按同一模式能力判断，音频 / 视频仍全部不提供。
- PC 检查焦点和 Web / Electron 宿主冲突；平板 / H5 的软键盘、IME、外接键盘和触摸入口由用户验收，不以桌面模拟替代真机结论。

- `PracticePage`持有唯一题目、面板、浮层与口语controller，所有底栏按钮、题面主动作和键盘调用同一`executeCommand`。`practice-footer`按游戏 / 模式 / 题态选择原稿顺序；音频 / 视频无知识动作，看图三种非指法模式有。
- `practice-bindings`连接既有学习设置的五项快捷键与固定流程键；`practice-shortcuts`纯解析作用域，`usePracticeCommands`仅注册单一监听并管理释放键位、IME、repeat、原生按钮去重与卸载清理。
- 答案 / 音标详情独立于题目phase；不再从顶部 / 底部答案按钮调用旧演示`toggle-answer`。真实切题清理媒体、重置口语及局部题内状态，设置不随切题清空。
- `features/learning-settings`公开校验后的五项快捷键与匹配能力，缓存继续用原键/version；含Ctrl旧值按第2.5节转换，保留主键及其余修饰键，冲突结果在设置和练习页反馈并停用。全局快捷键不按每种模式复制缓存。
- `TldDialog`继续处理最上层Esc/Tab、inert及回焦；普通编辑区、原生控件激活与作答输入分别处理，不导入Dialog私有层栈。

### 9.2 建议的单一链路

`活动作用域 + 内容族/小模式 + 题态/口语阶段 + 面板显隐 + 明确目标/可用素材 + 当前设置 → 可用动作解析 → 当前有效绑定 → 底栏/按钮提示与键盘派发 → 同一个动作执行入口`

实现留在practice page owner，按以下私有职责分工；`practice-bindings`额外作为底栏与监听共用的唯一键位来源：

| 建议所有者 | 职责 |
| --- | --- |
| `model/practice-shortcuts.ts` | 稳定动作目录、默认绑定、五项用户配置覆盖、归一化键位、作用域/阶段纯解析与冲突诊断 |
| `model/practice-footer.ts` | 各内容族/小模式底栏顺序、动作项与说明项、主动作标签；从已解析动作与有效绑定派生键帽，不再另写Shift/Ctrl/空格文案 |
| `model/usePracticeCommands.ts` | 在当前活动练习注册一个键盘入口；将按钮点击和有效按键交给同一executor；按现有Page/媒体/口语受控回调执行，并在卸载时清理 |
| `ui/PracticeFooter.tsx` | 受控渲染可见/禁用按钮和只读快捷提示；原生焦点与触摸入口保留，不保存另一份phase/binding |

动作能力与底栏布局分别声明：纯视频无底栏仍可按契约响应媒体空格；V/Esc可能不在底栏显示；按键也不能仅因UI隐藏仍绕过设置或能力门控。原稿合并的“Shift←→切题”“空格/←→跳格”若仅作说明，应作为非交互提示；只有可明确指向单一动作的项才渲染真实按钮，不能把复合键位框点击统一解释成下一题。

### 9.3 绑定与状态解析原则

1. 绑定继续使用第2节：Enter、空格、V、Esc、↓/↑面板显隐，既有朗读/掌握/不熟配置，以及默认Shift+←/→且可自定义的切题配置。主流程键不新增用户设置；更换默认键只改集中绑定与本文，不逐页替换字符串。切题提示读取有效配置，不能把默认Shift组合写死在各模式UI中。
2. 上下文按动作语义解析。例如同一`practice.primary`在输入为`question.submit`，自查未揭晓为`question.reveal`，结果为`question.next`，口语为当前录音/评测阶段动作。一个底栏主按钮可展示Enter与空格两个当前合法别名；口语结果的空格回放不是下一题别名。
3. 先处理普通编辑区/原生焦点控件、顶层浮层和口语，再处理底层题目；按钮聚焦时Enter/空格只激活该按钮一次，草稿多行Enter保留换行，作答输入Enter才按提交处理。IME、repeat与阶段切换后释放键位按第5节执行，只有真实消费才preventDefault。
4. 空格字符、输入方向键/选择文本、词槽导航、聚焦词块操作与实际媒体播停分别归属其作用域；没有明确目标词句时不推断口语目标，纯按键题不冒充词句评测。
5. 五项快捷键均由同一owner校验/持久化，旧Ctrl绑定按第2.5节一次迁移。冲突检测覆盖切题配置、流程键与同时活动作用域，不仅比较现有三个字段互相重复；现有合法Space/Arrow等历史值可能与流程或原生输入冲突，需要显式诊断和可见处理，不能静默覆盖、顺序抢键或重复执行。
6. UI点击与按键共用相同业务门控、素材可用性和反馈；本地演示动作与正式课程朗读、判题、录音评分、学习记录分别标记。当前无素材/服务的路径不因加了快捷键就宣称真实接入。
7. 本轮已确认练习Ctrl修饰键统一改为Shift；不假设preventDefault总能覆盖宿主保留键。实际Shift / Alt / Meta / 功能键在Web与Electron分别验证，Ctrl / Meta原生编辑组合仍按输入作用域保留。
8. 显式切题不依赖当前题是否完成；切换后统一重置题内临时状态。答案 / 音标详情用独立的show/hide动作，不能借用`question.reveal`或演示`toggle-answer`实现显隐；题内状态重置与长期设置缓存分别管理。

### 9.4 五项补充规则已确认

以下五项已由用户明确，且本地示例运行逻辑已接入；正式课程数据和学习记录继续按独立接口契约处理：

1. **切题默认值**：Shift+←上一题、Shift+→下一题，支持用户自定义；两端点击按钮与按键执行同一动作。
2. **答案显隐**：↓从页面顶部向下弹出，↑收起，参考哇学社独立顶部答案面板；与答题phase分开。
3. **音标详情**：↓/↑采用与答案相同的展开 / 收起方式，目标为截图的音标讲解区域，与自然拼读开关分开。
4. **看图知识按钮**：口语评测、中译英、沉浸听力都有掌握 / 不熟，指法练习没有；音频 / 视频仍全部禁止。
5. **切题状态**：未完成可以直接跳过；已完成 / 未完成题目切换后均重置题内状态，回看不恢复原作答。

部分玩法的答错、录音 / 评测结果细分没有独立底栏稿，继续复用第3节已确认行为，不作为新增键位或产品阻塞项。源项目的模式限制与自动展开策略只作参考，不替代上述规则。

## word:spell 输入聚焦命令例外（2026-10-20）

本节优先于历史“输入区保留Shift字符／裸方向键”的通用说明。仅word:spell由PracticePage显式开启answerInputCommands；↑↓、Shift+L/J/K和合法自定义绑定按当前能力、题态与设置执行，匹配后阻止对应输入，同次长按只执行一次但持续消费。不能执行的字符（如未到正确态的v）正常录入；Ctrl／Meta+A/C/X/V、IME／229、普通编辑器和弹窗阻断仍优先。答案显隐仅改panelVisible，不修改题态或恢复暂停，其他模式不启用此例外。

2026-10-20用户进一步确认拼写采用哇学社固定字母位。仅该模式的空格／Enter／底栏提交改经`WordSpellingInputController.submit`：未填满或仍有红色错位时只导航，原始／无音标向后一字母，音节／自然拼读向下一片段；填满且无待改错位时才执行一次校验。裸←／→由局部输入在字母／片段之间循环定位，Shift修饰的切题继续走原全局命令。Backspace／Delete先清当前位，空位再次删除才往前定位；局部已经消费的按键preventDefault并停止冒泡，长按空格／Enter不重复提交。Ctrl／Command+Z、Y／Shift+Z使用该模式内最多100次编辑历史；不声称保持OS原生Undo，也不回滚会话已计提交。其他模式仍沿公共整词编辑／原生撤销契约。按用户要求本轮未运行键盘、浏览器或构建验收，详情见[单词记录](practice-word-games-development.md#2026-10-20-拼写逐字输入与音标联动)。
