# 句中练义：打词填空与句中辩义（2026-10-21）

## 范围与入口

本轮按用户确认的五项方案扩展现有`word:meaning`，入口为`/practice/?demo=word-basic&mode=meaning`。两个玩法共享十道本地模拟题，首次进入为打词填空；切换只作用于当前会话，不新增路由、Storage键、接口或依赖。前三个已确认模式的完成检查点保持，句中练义本轮实现与实际UI验收分别记录。

音频范围经用户确认：接入现有全部交互音效，单词／整句朗读保留待接入口。录音、评分、回放继续全部模拟，不申请麦克风、不产生真实录音或成绩。

## 设计与四排布局

- 原稿：[打词填空546:31574](https://www.figma.com/design/z7SIwUb9ep0j0ZaEwFrxJl/ManiShare?node-id=546-31574)、[句中辩义546:31673](https://www.figma.com/design/z7SIwUb9ep0j0ZaEwFrxJl/ManiShare?node-id=546-31673)。已通过Figma界面核对两张画板、图层及属性；基准为1920×1080 CSS视口、100%缩放，题图430×242、圆角20，英文40px／400／normal。
- 原代码把meaning落入默写旧节点546:31470，并且不属于拼写／默写的四排容器；本轮新增专用`WordMeaningExercise`和`getWordMeaningReference`，不再消费旧通用题面或其自定义题态提示。
- 第一排为题面；第二排为固定46px口语入口槽；第三排沿原68px统计槽放292×46的双玩法选择；第四排仍是现有`PracticeFooter`。`WordSpellingResult.controls`只为本模式提供第三排内容及显式上间距，默认拼写统计／默写空槽保持。
- 题面采用流式布局。默认桌面题图距内容区顶部108px；填空与辨义的图片到句子间距分别为96／48px。英文行保留56px最小占位，输入与答案在同一Grid单元内自然参与测宽，目标词占位与共用字母槽的20px水平留白、12px底部空间对齐，输入字宽较大时可撑开句中槽；音标、词义与译文独立排布，不在各段制造纵向滚动。
- PC／Electron沿共用口语和底栏位置；低高度时题面、口语、第三排一起纵向滚动，底栏在内容滚动区之外。H5默认字号28px、平板34px、桌面基准40px，长句自然换行；图片不超过430px，窄屏按容器缩小，不缩放画布或根字号。
- 原稿英文使用MaoKenTangYuan(beta)，仓库没有可用授权Web字体；继续消费用户字体与项目回退，不宣称字体完全一致。上述为实现参考值，尚未执行浏览器计算样式／几何、真实缩放或视觉验收。

## 数据、输入与状态

- `model/word-meaning-demo.ts`提供十个独立目标：woman、sun、flower、butterfly、bag、dress、path、park、grass、walk。均取现有公园插图内可见的人物、物体、场景和动作，明确复用同一插图，不为其他词冒充新增图片。
- `PracticeQuestion.wordMeaning`是可选页面私有样例结构，包含英文前后文、中文前文／对应词义／后文、插图键及描述。文本用React安全片段渲染，不做HTML替换、自动匹配首个同名单词或推断后端字段。正式题目缺语境时显示缺项空态。
- 填空答案仍是`question.english`目标单词，句子前后文和标点不进入输入。直接消费`PracticeAnswerInput presentation="inline"`与`createWordSpellingLayout(target, 'syllables')`的latin整词回退，同时复用默写的字母槽渲染与键盘、鼠标、删除、纠错、撤销实现；其他消费者默认text／typing不变。
- 空值锁首位，点击只聚焦，普通左右键不移动；部分输入空格循环已填位置和首空位；完整提交后定位首错，删除再填或直接覆盖均自动推进下一待修改位，修改完空格／回车重新校验。沿用大小写设置、IME／229门控和Shift＋左右切题。判词走`judgeWordSpelling`和`submit-answer`，不新增拼写统计或黄晶规则。
- 填空保留音标、词义与整句中文，中文对应词绿色；正确时显示完整英文并标绿目标词，图片保留，按设置显示口语入口。手动答案面板不伪造成正确提交。
- 辨义直接显示完整英文、绿色目标词及可选音标，不创建作答input。首次空格／回车或点击提示显示整句中文并标绿对应词，再操作进入下一题；不触发正确提交、正确音或学习统计。
- `word-meaning` reducer只拥有玩法与中文显隐，主操作由`resolvePracticePrimary`统一分派。实际切题／重置隐藏中文并保留所选玩法；切换玩法保留题号、清理当前输入／错误／词块／中文，取消朗读与口语并更新轮次ID，恢复输入或题面焦点。同一玩法重复选择不重置。
- 底栏移除原“左右键跳格”提示。填空显示Enter／空格提交入口；辨义显示中文／下一题与对应动作，隐藏其底栏答案项。原生按钮的空格／回车由按钮处理一次；长按、IME、笔记编辑器及模态阻断规则保留。

## 输入框渲染对齐修正（2026-10-21）

初次实现只共用了`PracticeAnswerInput`的输入状态与事件，通过`PracticeWordSlotsInput.renderSlots`替换了默认字母槽。其整词3px边框聚焦时整条变绿，还保留`overflow-x-auto`；外层固定目标词测宽与绝对定位无法容纳部分输入／错误字符的实际宽度，导致截图中的横向滚动条。仅核对引擎复用不足以证明输入框完全一致。

用户确认后改为直接使用同一组件的默认字母槽，新增页面私有`inline`表现继承句子字号、去掉字卡顶部留白，复用4px灰色底线及当前逻辑位绿色光标。行内底线继续消费原solid／dashed设置；默认拼写／默写与其他词槽分支保持原样。移除填空的绝对定位及整词滚动层，Grid测宽允许内容撑开，窄屏／大字号在字母槽和句子层重排。此次没有更改键盘、IME、焦点、提交或纠错模型。

填空词字号单独跟随英文题面：`inline`显式设置`font-size:inherit`，默认沿题面28／34／40px的响应式字号；自定义字号由`WordMeaningExercise`同一个`displayFontSize`同时传给英文题面和输入器，输入态与答对后均以同一字号来源显示。此设置不改变拼写／默写的默认字号，也不新增独立设置或存储。仅格式与静态核对，实际字号、基线与缩放效果待用户查看。

用户截图显示输入词仍偏低后，进一步将填空Grid中的测宽占位与实际内容、`inline`表现的词组／片段／字母按钮统一改为`items-baseline`，让可见文字基线沿同一布局链传递。字卡原有`items-end`保持；底线绝对定位和底部留白继续只用于绘制，不使用固定像素上移或transform补偿。输入事件与渲染结构不变，本次仅格式及静态差异核对，实际基线与多字号／换行效果待用户验收。

补充未执行的SSR回归：填空空值／部分值／较宽错误字母均使用五个默认字母位，无旧词槽滚动分支；与默写比较同一反馈下的字母、错误颜色与逐位底线；保留单一真实input及底线设置。SSR断言不代替浏览器的宽度、基线、缩放和实际按键验收。

## 音效与口语复用

- `PracticeFeedback`继续消费`features/learning-settings`根入口的37份注册音源和设置音色／音量。有效打字、判定后的正确／错误、实际切题、课程完成、录音开始及评分等级沿既有事件、去重和清理能力接线；提交反馈使用判定后的正误声，不虚构独立提交音源。没有复制音频或首屏批量预加载。
- `OralAssessmentDialog`／`useOralAssessmentDemo`通过feature根入口接入。填空仅正确且开启“显示口语评测”时显示；辨义因目标词已展示，按该设置直接提供入口。点击与V共用同一门控。
- 评测对象沿单词模式为当前目标词及词义。目标ID包含模式、玩法、题目与重练轮次；切题／切玩法／关闭取消过期任务。准备→模拟录音→评测中→固定样例结果、V、重录、模拟播放和设置声纹均沿既有组件；不接旧口语演示面板。
- 无`readingSource`时`usePracticeReading`不创建课程Audio。朗读按钮／Shift＋朗读、切读开关和已有缺音源提示继续保留；不接TTS、补查接口或拿技术音调代替课程朗读。
