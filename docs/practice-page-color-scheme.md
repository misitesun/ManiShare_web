# 练习页配色方案

更新日期：2026-10-15。来源：用户本轮提供的词性 / 句子成分配色表图片。本文是练习内容配色规范；第一版已将实际fixture使用的8项词性/成分色纳入语义token，其余仍待数据覆盖；页面结构与当前静态 UI 范围见 [练习页开发文档](practice-page-development.md)。

## 1. 使用范围和边界

- 当前没有后台接口，先使用明确标注词性、句子成分的本地示例数据展示配色。不调用分词、语法分析、翻译或补全服务，也不根据文本自行猜词性。
- 这是练习内容的配色方案，不是新增第三套全站主题，也不自动新增设置中的方案选择器。现有 dark / light、背景方案、答题颜色和文本颜色仍是独立概念。
- 表格的白色纸面、绿色表头、黑色网格及“第1页 / 第2页”水印是资料排版，不作为练习页 UI 配色。
- 原表两组均没有编号 6；下表保留原编号，不自行补入其他分类。未明确的色值与含义列入第 5 节。

词性“助动词”为 `#01f799`，句子成分“助动词”为 `#b4b4b4`。它们属于两种标注维度，不能用一个中文名称到颜色的字典相互覆盖。

## 4. 与现有设置的关系

| 对象 / 设置 | 作用范围 | 调整语法填充亮度时 |
| --- | --- | --- |
| 底色 | 原表注明“固定不变”；没有给出具体色值或精确区域 | 不跟随此滑块变化；不据此锁死全站主题或用户背景选择 |
| 词性标注 | `showPartOfSpeech` 控制显示 | 保留第 2 节颜色 |
| 句子成分文字 | `showGrammarText` 控制标注文字 | 保留第 3 节基准色 |
| 句子成分划线 | 随相应成分标注呈现，具体开关归属待确认 | 保留第 3 节基准色 |
| 句子成分填充 | `showGrammarFill` 控制填充显示；关闭时沿用当前预览的填充与填充边框透明行为 | 仅此层随 `grammarBrightness` 调整 |
| 普通正文 / 答题文本 | `textColor` / `answerColor`，与背景独立 | 不被此滑块整体变暗 |
| 用户背景 | `backgroundPreset`、背景图片、遮罩和模糊 | 遮罩、模糊保持各自设置语义，不被此滑块联动改写 |

当前设置源码中 `grammarBrightness` 为 1–10，默认 4；[现有预览推导](../src/fsd/features/learning-settings/model/appearance-preview.ts) 使用值 / 10 作为填充透明度。这是当前实现事实，不等于原图已指定新方案采用透明度、HSL 亮度或混色公式。静态 UI 可沿用现有预览方式作演示，需注明；最终算法确定后统一设置预览和练习显示。

实现时将词性、成分文字、划线、填充分层，禁止对整个句子容器设置 opacity / filter 来模拟亮度。填充边框与语法划线不是同一个图层，不能因关闭填充而误删仍需显示的划线。语法文字与填充的开关独立，不因关闭文字自动关闭填充。

组件只能消费语义主题 token。[全局样式入口](../src/fsd/app/styles/index.css) 已将首版8项颜色区分为词性和句子成分命名空间，包括 `practice-pos-verb` 与 `practice-syntax-predicate`；剩余分类在有明确数据消费者时继续补齐。不得在组件中散落 HEX、随机选色或按 dark / light 写业务分支。

## 5. 待确认项与静态阶段处理

1. “其他词性”的具体浅色及“其他未知”句子成分色值：不自行补造；静态样例优先覆盖已定分类，未知项用已有中性文字并标记未配置，最终颜色待补充。
2. 原表“主语谓语you're”的准确含义、数据标记和适用范围：暂不推导成语法解析规则。
3. 固定底色的具体 HEX、适用容器，以及语法颜色与用户自选正文 / 答题色的优先关系：亮度滑块不联动这几层，但相互覆盖顺序尚未给出。
4. 填充亮度算法、划线显示开关归属及深浅主题下的可读性：先在静态样例对比，再确定最终规则。若需要修订固定标注色，应更新本方案，不自行替换原表值。

以上缺口不阻塞已明确分类、分层和滑块作用边界的静态 UI 开发；不能用缺口为理由调用额外接口补齐标注。

## 6. 后续实施验收

- 逐项核对两组已明确 HEX；同名“助动词”在两种维度分别正确显示。
- 滑块最小、默认、最大值下，底色、词性、成分文字和划线保持不变，只有开启的填充层变化。
- 分别关闭词性、语法文字、语法填充，确认作用层独立；填充边框与划线按各自规则处理。
- 检查 dark / light、背景图及现有背景方案、文字自选色、长句换行，避免标注错位或互相遮挡；颜色之外保留文字名称或结构提示。
- PC 按设计基准核对；平板 / H5 的视觉和真机可读性待用户验收。本文只整理方案，尚未进行页面视觉验收。
