# 猜词游戏静态 UI 开发完成检查点

日期：2026-10-26。用户确认猜词游戏静态UI开发完成，并授权将本轮代码、素材和记录在`main`提交、推送至`origin/main`。本次在`8a53e49`之上归档猜词、阅读、打词三个模式；静态UI完成不表示正式接口、测试、构建或各端兼容验收通过。

## 本次完成范围

- 猜词模式：场景图、中文语境和可点击目标词，点击目标词或顶部答案打开右侧卡片；默认Shift＋左右键切题，题面空格／Enter不切题，朗读与切读复用既有声音调度。
- 阅读模式：十条中文语境与音标／目标词垂直列表，点击单词或切题自动展开对应答案。阅读滚动区域铺满顶栏和固定底栏之间的可用屏幕，滚动条靠最右侧，正文保持版心与上距；活动行不可见时才调整滚动位置。
- 打词模式：430×240场景图，中文前文＋单词输入槽＋可选中文后文，848×315动态虚拟键盘及手型；默认抄写，保留默写、图片、键盘与切读选项。只对英文目标词作本地输入／判题，空格／Enter提交与正确后继续，复用句子指法的原生输入、整段纠错、IME与撤销；键盘前留白按最新反馈统一为句子指法的70px。
- 共用答案卡：三个模式共用`GuessWordAnswerPanel`与页内`WordLearningCard`猜词变体，默认位置与草稿一致，保留右侧滑入、渐变描边、阴影、Y轴解析翻转、内部滚动和音标方案。修正翻转过程固定外框、滚动裁切及快捷键切换后的外层焦点框；内部真实操作仍保留键盘焦点提示。
- 数据和声音：共用hand、man、girl、boy、book、apple、water、sun、green、happy十条模拟题目，green保留后文以覆盖句中填词。hand使用本地离线合成WAV，其余复用原整词音源；题图／答案遮罩、例句播放、提示音等待与旧请求取消沿原会话。
- 答案与输入状态：打词正确后自动展示答案，手动查看只开面板、不清作答；关闭后恢复输入／原纠错位置。切题清空打词作答并收起旧答案，阅读有效切题自动开新词答案，末题沿原完成窗。打词黄晶1200只为原稿静态展示，没有新增真实计分规则。
