## 2. 产品概述

漫奇说（ManiShare）是以英语学习为核心、叠加游戏化成长、会员服务、用户创作、社交激励和推广分佣的学习平台。

主要价值链为：

1. 用户通过微信扫码或账号方式登录。
2. 在课程市场选择课程包和章节。
3. 学习章节内容；练习页按新版开发文档先进行静态 UI 与本地交互演示，尚未接入真实练习服务。
4. 学习行为累积时长、等级、境界、打卡天数和积分资产。
5. 用户可参加 PK、AI 情景对话、风采大赛和奖励兑换。
6. 会员可获得不限时学习、专属内容、口语评测、社群、AI 创课资源和推广权益。
7. 用户可创建课程包、章节与内容，并管理发布状态。

## 3. 用户、身份与资产体系

### 3.1 用户身份

| 身份 | 原型定义 | 核心差异 |
| --- | --- | --- |
| 未登录用户 | 尚未完成登录或注册 | 进入扫码或账号登录流程 |
| 免费注册用户 | 完成注册但未购买会员 | 每日学习时长受限；部分课程或章节需付费/升级 |
| 体验版 | 新用户可领取 3 天不限时体验 | 属于“体验用户”，不等同于黄金 VIP |
| 萌芽版 | 每天 30 分钟；邀请好友可增加体验时长 | 属于“体验用户” |
| 黄金 VIP | 周卡、月卡、季卡、年卡 | 解锁 VIP 内容、无限口语练习等 |
| 终身 VIP | 远见版/终身卡 | 终身权益及推广分佣 |
| 漫奇联创天使 | 高阶终身会员/事业共创人 | 终身权益、专属社群、内容定制和更高推广收益 |
| 分公司用户 | 后台单独配置 | 仅该身份显示“分公司”图标入口 |

身份展示位置包括全局侧栏用户区、玩家资料、课程权限提示、排行榜、PK 房间、分享奖励和风采大赛。

### 3.2 等级与境界

- 等级按累计练习时长升级：每累计 10 小时升 1 级。
- 原型展示的等级分段为：`Lv0-Lv4`、`Lv5-Lv19`、`Lv20-Lv39`、`Lv40-Lv59`、`Lv60-Lv79`、`Lv80-Lv99`、`Lv100+`。
- 已出现的境界示例有“初音”“语通”“意凝”；最高境界为“言灵”，Lv100 以上均显示“言灵”。
- 完整的等级—境界名称映射未在可读文字中给全，需要补充正式配置表。

## 5. 登录与注册

### 5.1 开屏页

- 展示品牌名称、品牌主张、311N 学习法介绍及登录入口。

### 5.2 登录方式

- 微信扫码为默认和优先入口；批注明确手机端和电脑端都优先展示微信扫码。
- 另提供账号登录、验证码登录、立即注册。
- 登录时展示《用户协议》和《隐私政策》同意提示。

### 5.3 注册字段

- 邮箱或手机号。
- 验证码。
- 密码。
- 邀请码，非必填。

### 5.4 2026-10-14 前端改版确认

最新事实来源为用户提供的Figma六节点与哇学社公开登录/注册入口。品牌首屏采用地球背景和翼图；点击登录默认微信扫码界面，并支持手机号+密码、手机号+短信验证码、海外邮箱+密码、海外邮箱+邮件验证码，共五种方式。注册支持手机号、海外邮箱与微信入口；表单含账号、验证码、密码和选填邀请码，并勾选用户协议及隐私政策。输入非空后显示清空和密码显隐。

### 6.3 学习花园

学习时长驱动花盆/嫩芽成长：

| 当日学习时长 | 展示状态 |
| --- | --- |
| 大于 0 且少于 30 分钟 | 花盆 |
| 超过 30 分钟 | 小嫩芽 |
| 超过 1 小时 | 增加一层叶子 |
| 超过 2 小时 | 再增加一层叶子 |

### 6.4 每日打卡

- 初始累计打卡数建议 50000，可由后台配置。
- 默认完成 10 分钟学习后可打卡，阈值后台可配置；配置为 0 时无需学习即可打卡。
- 每名用户每天最多打卡 1 次。
- 打卡后按钮显示“今日已打卡”并进入不可再次点击状态。
- 总数按打卡次数累计，不按唯一人数累计。
- 用户侧只展示累计打卡天数。

### 6.5 Mani 吉祥物与语录

- 吉祥物方向：夜晚使用电脑的女性、透明翅膀、大眼独角兽等品牌元素；最终素材待提供。
- 首次进入页面时以打字机效果播放一句话，动画只播放一次。
- 语录一行一句，每 2 秒轮播一条。
- 后台可维护语录内容。

### 6.6 打卡弹幕

## 13. PK 争霸

当前代码已实现 `/pk/` 示例大厅与侧栏入口，包括三位置活动插画演示轮播、个人统计示例、我的创建、房号搜索、房间卡和胜利/场数/胜率榜。搜索、轮播、榜单切换与确认取消为当前页本地交互，取消同时移除大厅对应示例房间，重新进入恢复示例；未接入真实房间状态、在线检测、实时通信或计分。创建已接完整本地配置弹窗；PK数据提示暂未开放；随机/快速开始和进入等待已接两个全屏状态演示页，固定示例匹配房间、邀请/机器人提示未接入，开启只显示72%加载、不开发练习。Figma 给出的完整流程为：大厅 → 创建/加入房间 → 匹配等待 → 加载 → 对战答题 → 结算 → PK 记录/再次对战，其中匹配中和加载已实现本地视觉/导航演示，真实服务端流程及后续答题/结算尚待实现。

### 13.1 大厅与个人数据

- 个人数据：参与、胜利、失败、逃跑、胜率。
- 操作：创建房间、随机进入、快速开始、我的创建。
- 房间卡：房号、房主头像/昵称/身份、在线状态、创建时间、课程、章节、模式、抄写/默写和进入等待。
- 用户只要仍在站内，即使处于其他页面，也应显示在线。
- 展示房间创建距今时间，支持按房间号搜索。
- 侧栏或大厅展示胜利榜、场数榜和胜率榜。

随机进入规则：

- 有在线且可加入的房间时，进入大厅排序后的第一个房间。
- 没有在线房间时提示“暂无人在线，可自行创建房间”。

### 13.2 房间生命周期

- 未创建房间时显示“您未创建任何房间”。
- 创建成功且未匹配时，可进入等待或取消房间。
- X 小时未匹配成功自动删除，X 由后台配置。
- 自动删除后，大厅和“我的创建”均不再展示。
- 已开始房间的大厅展示规则存在冲突，见待确认事项。
- 房间状态至少需要区分：等待中、已满员/可开局、加载中、对战中、已结算、已取消、已过期和异常中断。

### 13.3 创建房间

配置项：

- 对战类型：真人对战、人机对战；人机对战设计为添加机器人。
- 难度：困难、容易。
- 游戏类型：句子游戏、单词游戏。
- 课程。
- 章节，可多选并显示已选数量。
- 模式：中译英、听写、选词拼块等。
- 默写/抄写。
- 主题：默认、闪电及另一套主题，2～3 套即可。

课程与章节规则：

- 言灵觉醒至入门特训的课程均可用于 PK。
- 选择句子游戏时仅句子章节可选；选择单词游戏时仅单词章节可选。
- 选词拼块只适用于句子类题目。
- 课程卡本身不区分权限，章节需要区分免费、VIP、终身 VIP。
- 参与者无论是否付费，都可加入已经创建的游戏；创建者可选章节的权限规则存在冲突。

### 13.4 匹配、加载与开局

- 等待页展示课程、章节、模式、房主身份和双方席位。
- 房主可邀请用户、添加机器人、取消对战和开启对战。
- 参与者等待房主开启，页面提示“等待房主开启 PK，请勿离开该页面”。
- 开局前进入双人加载页，分别显示玩家头像、昵称、身份和加载百分比。
- 任一方加载失败、超时或离开时的恢复/判负规则尚未定义。

### 13.5 对战答题

- 页面左右分别展示两名玩家的头像、昵称、题目、输入/答案区和当前进度。
- 顶部使用蓝/粉双色比分条，中部显示共享倒计时和“每答对一题得 +10 分”。
- 设计示例的单题倒计时为 20 秒，但是否后台可配尚未说明。
- 设计中双方示例题目不同；实际比赛是同题同步还是各自题序，需要在实时对战协议确定前确认。

### 13.6 结算与记录

1. 任一玩家先答完全部题目时，比赛立即结束。
2. 最终按得分判断胜负，不按完成速度直接判胜。
3. 每答对 1 题得 10 分，答错得 0 分。
4. 未答完期间任一方退出或掉线，退出方直接判负，不考虑当时分数。
5. 结算浮层展示双方得分、胜负/逃跑状态、完成时长、总题数、答对数、答错数、正确率、答题时长和连对数。
6. 结算后可再次 PK；重新匹配同一对手、重新使用当前配置还是返回房间，尚未定义。
7. PK 记录支持所有、胜利、失败、逃跑筛选，并预留“PK 数据/答题记录”入口；详细逐题记录可作为后续范围。

### 13.7 PK 排行榜

- 胜利榜。
- 场数榜。
- 胜率榜。
