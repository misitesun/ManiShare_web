# 看图学词 · 口语评测

## 本轮范围

2026-10-26，用户要求完全复用句子游戏口语评测，仅将看图学词封面指定为520×360，其他内容完全一致。本轮接入现有 `picture-basic/oral`，替换通用占位口语题面；沿既有十条看图单词／短语和朗读素材，不新增路由、正式接口或业务资源。

## 组件与流程

`PracticePage` 显式识别 `isPictureOral` 并加入既有 `isOralExercise`。录音开始／结束、评测、结果、重新录制和回放均由句子模式使用的同一个 `useOralAssessmentDemo` 管理；不另写阶段或计时器。页面声纹继续注入现有 `LearningAudioWave`，按录制／播放状态消费设置，提示音、Space、V、Enter和Shift切题沿原命令入口及最上层浮层阻断。

`PracticeContent` 注入 `WordOralAssessmentExercise family="picture"`，直接装配同一 `OralAssessmentContent presentation="page"`。英文、中文、录音按钮、录制声纹、逐词模拟分数、总分和准确度／流畅度／完整度、重录／回放与句子模式完全共用；仅封面slot和内容目标来自看图。翻译显隐继续服从看图口语局部设置，切读和手动朗读继续同源WAV及原调度。

指法封面页内组件更名为 `PictureExerciseCover`，由指法和口语两个真实消费者共用；两者均为520×360、圆角20，原浴室场景和静态绿色区域框保持。图片资源仍名 `picture-typing-scene.png`，不复制资源或引入临时Figma链接。口语的媒体槽只传展示和朗读回调，不拥有播放器；录制／评测中封面disabled且朗读命令被现有口语阶段阻断，避免示例音干扰录制。

新 `picture-oral-demo.ts` 与听力、指法、中译英共用十条词例及五份既有WAV，独立 `picture-oral:*` 题目身份隔离访问和评测结果。目标kind仍按真实单词／短语使用word，不伪造句子题或后台字段。题号变化、重练和卸载沿原控制器重置、取消任务及媒体组清理；同词不同题仍拥有不同访问版本，旧结果不能进入新题。

顶栏内容沿看图共用 `VideoPracticeLayout variant="picture"`／`PracticePlaybackList`，十题列表只传题号，不传视频时间戳；PC侧栏与题面、底栏联动，窄屏沿原内容模态。顶栏答案使用句子答案面板，录音评测本身不另弹窗。看图口语的掌握／不熟及其他原底栏动作保持，未增加指法统计或黄晶奖励。

## 布局与兼容性

按用户后续截图调整滚动条：此前滚动宿主和1390px限宽题面是同一节点，滚动条因此出现在页面中部。本模式显式启用 `VideoPracticeLayout.edgeScrollbar`，独立滚动视口覆盖左右12px／平板以上30px的外层留白，让关闭侧栏时滚动条到达内容最右侧；内层题面继续使用原宽度和居中逻辑。PC内容侧栏打开时，通过同一GSAP时间线同步插值视口宽度，保留列表前23px间距；窗口宽度变化沿原ResizeObserver定位，所有订阅和动画按原方式清理并尊重reduced-motion。题面不再另设纵向滚动，透明轨道配细滑块，标准scrollbar属性与WebKit回退均使用现有语义主题色，不新增主题token。后续检查后，沉浸听力／中译英／指法也通过同一变体统一处理；内层继续flex伸展和至少视口高度，保留中译英答对页底部口语布局。视频等其他内容族仍保持默认滚动宿主。

仅替换媒体槽尺寸，正文和各阶段纵向排版使用句子口语原组件。默认设计断点的封面前上距继续为idle 172px、录制／评测144px、result 107px，均相对75px顶栏后的内容区；520×360封面使后续正文自然向下排布，不采用旧通用看图口语的绝对位置。字体、行高、字距、录制／评分布局和所有按钮保持同一实现。

封面宽度上限520px、按520:360等比收缩，短屏在原内容区域滚动，固定底栏和安全区保留；不缩放画布、根字号或抵消浏览器缩放。默认dark／light沿现有语义token，原生按钮可聚焦和键盘激活。首次渲染、偏好／Portal恢复、同源音频、媒体取消与文本输入等兼容契约保持；无Next适配、Storage、主题token、依赖、CSP或Electron bridge变化。
