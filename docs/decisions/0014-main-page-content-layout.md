# 0014：常规主内容页采用流式版心与宽屏自适应网格

## 背景

玩家档案列表最初按设计稿固定版心和三/四列数据，在超宽 PC 上导致两侧空白过多；原有 `xl:px-0` 又在约 1400px 窗口中清掉了最小留白，使内容贴住侧栏与右侧边缘。用户确认修正五页，并将适配方式作为后续同类页面的默认规则。

## 决定

- 具体数值、Tailwind 示例与验收矩阵统一维护在[架构约定的 mainPage 章节](../architecture.md#mainpage-版心与列表适配)，开发规范、需求清单和实现/审查 Skill 引用该来源。
- 常规列表/管理页在较窄 PC 上使用统一精确留白，宽屏使用固定外侧留白与可增长的内容区；两个 PC 区间均不保留页面级固定最大宽度。设计稿列数不作为永久限制，网格按实际最小卡宽自动排布。
- 规则由页面维护，不改写整个 App Shell，不添加全局业务 class 或窗口尺寸状态。保留平板/H5 已有边距，不机械迁移无关页面。
- 登录、首页仪表盘、编辑器等特殊布局按实际需求处理，并在所属 README 记录例外。

## 取舍

优先保持内容可读性与不同窗口尺寸的空间利用率，而不是把某一张设计稿的固定宽度扩展到所有屏幕。已确认的断点切换可以改变版心宽度；不额外引入未经要求的缩放或连续插值。曾只补最小留白并保留两套最大宽度，导致 1500px 时五页仍分成 16px 与 60px 两组边距；用户确认收紧为统一实际边界，因此移除五页旧版心上限，保留较窄 PC 的既有列数。

## 验证

运行 test/lint/build，并按 mainPage 章节检查 PC 断点两侧、超宽屏、侧栏状态、实际计算边距与溢出。纯样式不使用源码字符串匹配充当行为测试；平板/H5 视觉及真机验收交由用户。
