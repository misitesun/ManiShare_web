# 练习文本输入与原生编辑历史

## 猜词打词单词段接入（2026-10-26，未新增兼容验证）

`GuessSpellingExercise`以单个英文目标词段消费既有`SentenceAnswerInput`，中文前后文只展示，不进入值或判题；复用原生输入、IME／229、整段纠错与命令单次消费。可选无障碍label默认仍为“句子答案”，其他消费者行为保持。答案独立浮窗不清输入，收起后沿控制器恢复原作答／错段位置；默写键盘不提示隐藏目标，键盘隐藏不删除输入。按题目ID／revision重建，单词音源沿原调度；只补回归源码、格式及差异检查，未运行测试、构建或各端输入／焦点验收，不增加真机兼容通过声明。

## 纯指法混合目标接入（2026-10-23，未新增兼容验证）

纯指法是`SentenceAnswerInput`／`sentence-answer-input`的新增页内消费者：统一目标文本，单词一段、短语／句子多段，内部撇号与连字符保持可编辑、句末标点沿静态前后缀。按题目ID／revision重建输入、纠错、编辑历史及键盘快照，不能仅因两题均有`word-slot-0`就沿用旧状态。仍由`PracticeInputBridge`承接原生输入，不复制输入器或按数据类型切换原生编辑语义。

首次填齐空格提交、完整段值校验、首错完整选区、原生同值input、IME／229、Undo／Redo及捕获／冒泡单次消费继续沿既有规则；纯指法只关闭自身朗读／口语／答案／知识命令，不拦截原生大写或编辑组合。当前只有新增回归源码、定向格式化与静态差异核对，没有新增测试、浏览器、Electron或真机通过证据；按用户约定各端实际输入留待用户验收。实现及混合样例见[纯指法记录](../practice-typing-game-development.md)。

## 分段首次填齐后原地空格提交（2026-10-23，待用户验收）

共用`sentence-answer-input`修复首次作答只能在末段空格提交的限制：所有实际词段均非空且尚未提交时，从任意活动段按空格直接走原整句判题；例如先填`writes / stories`、再回首段补`he`，无需重新跳到末段。填齐表示允许提交，不表示文字已正确；错误仍定位首错，提示文字和空白不算真实输入。

该模型同时用于句子／音频／视频中译英及共用分段输入的指法页面。未填齐时的跳段／末段回首空段、已判题后的纠错导航、已正确尾段快捷提交、Enter／按钮、IME／229、原生输入与去重保持。本条覆盖下方和历史文档中的“首次空格仅末段提交”。补充乱序补齐、任意活动段提交、正误判定及防止重复提交回归，但按用户要求未执行测试、构建或浏览器／设备验收，仅格式化和静态差异核对；各端真实输入待用户验收。

## 句子中译英按段输入例外（2026-10-22，待用户验收）

句子整段纠错必须接收“原生编辑发生但字符串相同”的事件，例如错误`g`全选后再键入`g`。句子组件使用`onInput`作为唯一原生文本事件入口，不能仅依赖React`onChange`按值派发；清除错误反馈同样计入编辑历史。保持组合缓冲与结束重放去重，不并行注册两个文本处理入口，也不以合成字符事件补写。新增模型回归未执行，实际设备现象仍待用户验收。

错段修改按用户要求以整段为单位：提交定位首错并设置该段UTF-16完整原生选区，首次字符覆盖整段，Backspace／Delete及原生删除清空整段；首次修改后清当前段反馈，再恢复正常编辑。切换／归焦错段、重复提交以及首错位置未变化均须重新同步选区，不只监听活动索引；不能以段尾光标造成追加或逐字删除。其他段、组合期与229门控、原生剪贴和模型Undo／Redo保持，实际多端效果未验收。

用户确认中译英与单词输入分开维护，`SentenceAnswerInput`／`sentence-answer-input`按题目词段保存实际字符串，空段与超长词不丢失；仅共享`PracticeInputBridge`原生载体，单词原状态／IME／回调保持。句子的普通左右与空格用于跨段，所有段非空后Enter／按钮才判题，未填齐时只向后导航、末段回到首个空段；首次作答所有实际段非空时，可从任意活动段按空格判题；纠错中当前段已编辑、后续段全已判对且每段非空时可原地空格判题，其他非末段情况只向后跳段；下方固定字母容量与左右屏蔽规则不再约束`sentence:translate`。页面既有捕获命令先处理上下答案、Shift切题和提交，局部处理必须让行`defaultPrevented`，保留IME／229及去重边界。

原生input只传当前段文本，组合期缓冲不判题，组合结束提交一次并防止原生重放。复制／剪切保留当前段的原生编辑语义，无程序剪贴板访问；不调用execCommand、setRangeText或合成字符事件。分段导航不通过补空格或重写整个句子改变编辑位置，最多100次模型Undo／Redo恢复段值与活动段且不回退提交次数；不声称等价于系统原生Undo。句子按原始数组逐段判题，不能trim或拼接后把空段和错位误判正确。

本轮仅有源码与未执行的模型／SSR断言，没有新增浏览器或设备验证证据；按用户要求不运行测试、构建、浏览器或Electron。原生输入、粘贴／IME、真实缩放和各端效果均待用户验收。其他消费者继续遵守下方当前字母输入契约。

## 当前契约：全模式受控作答（2026-10-21）

句中练义的打词填空直接使用`PracticeAnswerInput presentation="inline"`及默认latin整词回退布局，同时复用拼写／默写的字母槽和4px逐位底线，不再通过`PracticeWordSlotsInput.renderSlots`替换外观。行内表现只调整句中尺寸、留白与重排，保持默写英文字母、逻辑光标、空格推进、纠错、IME和快捷键规则；句中辩义不创建作答input，空格由题面流程解释为显示中文／继续，不进入文字编辑。切换玩法清理当前作答并更新轮次，回到填空后再由原归焦调度恢复。该消费接线仅做静态核对，就近用例已保存但未运行；不冒称新增浏览器或真机兼容证据。

全部真实文字作答现由 `PracticeAnswerInput`／`word-spelling-input`拥有逻辑位置。鼠标和左右键不定位；未输入锁首位，部分输入空格循环已填位与首空位，Enter仅完整校验，纠错自动推进。纠错期间逐位或选区删除原先正确的字母，也须将新空位加入有序待重填列表；例如`woean`判错后回删前三位，重新输入必须依次经过`w→o→m`，不能只追踪原错位而跳过新空位。该回归已补模型用例但未执行，多端实际输入待用户验收。两个历史视觉入口均已复用同一实现，旧的点击补空格和原生选区定位已移除。组合文本与229期间不接管输入；保留真实input传输、全文编辑与模式内Undo，复制／剪切经批准剪贴板入口输出作答全文。

作答输入聚焦时，`usePracticeCommands`在捕获阶段先处理页面快捷键，包括配置中的Shift＋左右切题；命中后输入器不重复处理，未命中的定位键仍被屏蔽。其他控件和弹窗维持原冒泡顺序，捕获和冒泡监听互斥处理作答输入。事件顺序、去重和IME门控须一起保留，不能只在纯命令解析测试中确认绑定存在。

归焦沿输入控制器`focus`保留当前作答和纠错位置。拼写等卡牌翻转结束且可见后归焦；模式局部设置在控件自身还焦后的下一帧请求，全局设置在弹窗退场后请求。执行时重新检查可编辑性及disabled／inert，暂停或弹窗期间不抢焦点，卸载取消待执行帧。不使用全局blur强制聚焦，也不据DOM聚焦推断H5系统软键盘已弹出；实际多端交互仍待验收。

模式选项浮层允许焦点返回同一练习输入而不关闭，仍响应外点／显式关闭。Esc由局部浮层先消费，作答输入的Esc保留冒泡，不先派发页面暂停。PC hover展开不抢焦点，平板／H5点击；共用触发规则与未执行验证边界见`shared/lib/popover-trigger`说明。真实鼠标、触控、Portal焦点和IME仍待用户验收。

入口、全部消费者、状态规则、UTF-16、键盘提示、本地校验范围和待验收矩阵见[全模式推进记录](../practice-answer-input-development.md)。本轮只格式化和差异检查，未运行测试、构建或运行时验收。

- **2026-10-21方向键与答题光标分离。** 拼写／默写的普通左右键只选择独立音标／输入段高亮，不能复用空格待填导航去改变答题光标；单段可重复反馈，多段边界不循环。真实输入的选区缓冲仍按既有规则折叠，Ctrl／Command编辑组合、Shift选区与IME／229不进入这条高亮处理。只要仍有待纠错位，编辑已处理字母后也继续下一错位，避免全文已填满时停在该位。空格／Enter待填导航、鼠标定位和全部修改后重新校验保持。源码依据、根因和新增未执行回归见[默写差异核对](../practice-word-dictation-development.md#本次差异核对)；本次仅格式化与静态核对，真实键盘／软键盘、Web／Electron及各端动画待用户验收。

- **2026-10-21例外扩展：单词默写。** 用户确认`word:dictate`复用拼写的`WordSpellingInput`／`word-spelling-input`固定字母位、错误展示和纠错跳转，覆盖下方历史记录中“仅word:spell”的适用范围。默写把整词作为一个布局分组，直接使用拼写输入器的整词回退分组，活动横线按目标字宽显示，不保留默写专用输入分支；点击未填位置统一取首个空位，已填字母仍可定位编辑，避免初次点击跳过首字母。四档音标切换不拆开输入字母位。两种模式的空值点击、方向键、分组定位、空格／Enter及删除都固定首位；局部选区删除保留待纠错身份，整词清空重置光标和过期错位，重新聚焦保留当前纠错位置。抄写回显只改变空位提示，不填入真实答案。真实input承接键盘／剪贴板／IME、组合期间不提交／移动、组合结束过滤ASCII字母、原生缓冲与逻辑光标分离、最多100次模式内Undo历史等既有行为均保持。页面只对拼写与默写显式启用作答快捷命令，保留Ctrl／Command编辑组合、IME／229及按键去重；其他模式继续原整词编辑路径。本轮补充源码回归用例但未执行，仅格式化与静态核对；Web／Electron的IME、剪贴板、软键盘、长词和PC／平板／H5视觉效果仍待用户验收。

- **2026-10-20当前例外：单词拼写。** 用户确认按新版哇学社的固定字母位与纠错流程重做`word:spell`，其入口现为`WordSpellingInput`／`word-spelling-input`。以下整词编辑和原生Undo契约继续约束`PracticeWordSlotsInput`及其他消费者；历史拼写的末词提交／公共feedback透传记录不再代表当前拼写输入。新输入仍用真实input接收原生键盘、剪贴板和组合缓冲，组合期间不判题或移动选区，结束后只接收ASCII字母；不使用全局字符兜底、execCommand或合成输入事件。字母位与逻辑光标由模式模型拥有，真实缓冲只含已填字母，字母更新后会在非组合期把原生光标移到缓冲末尾；此行为有意区别于下方整词原生编辑路径。Ctrl／Command+Z、Y／Shift+Z使用最多100次模式内历史恢复字母／错位／逻辑光标，不回滚会话已计提交，不冒称与OS原生Undo等价。切换提示／音标及翻面保留字母，切题／重练释放模型；其他模式不引入此例外。仅补模型和SSR用例、定向格式化／差异核对，未运行测试、构建或浏览器操作；真实IME、软键盘、剪贴板、Web／Electron及PC／平板／H5仍待用户验收。详见[单词实施记录](../practice-word-games-development.md#2026-10-20-拼写逐字输入与音标联动)。

- 适用范围：`pages/practice` 的整词可视槽、真实答案 input、词槽点击和原生撤销/输入法；不是通用富文本编辑器或判题策略。
- 已确认现象：2026-10-19 Electron 43 的隔离原生输入探针中，先原生录入 `brush` 再通过 `input.value='brush '` 补定位空格，Undo 无法撤回原有录入。原生录入路径能够正常撤回。因此“完整值未丢失”不能替代编辑历史验收；React 受控值在原生事件之外被程序改写也须避免。
- 唯一入口：`src/fsd/pages/practice/ui/PracticeWordSlotsInput.tsx` 接收完整原生字符串；`model/word-slot-input.ts` 只派生词槽、测宽占位和 UTF-16 选区。`TypingKeyboard`只读原生输入与物理按键，不生成文字。
- 必须保留：普通输入、空格、删除、选区替换、粘贴、撤销、重做及组合输入使用真实 input；不在 Effect 中反复写 value 或把光标拉到末尾。Enter 使用既有统一提交，Tab/Shift+Tab 使用原生焦点。已存在词的点击只改变选区；组合期间不做程序选区或补字。
- 2026-10-19单词拼写特例：仅该模式在最后词槽已填、全文末尾无选区时把普通空格解释为提交；keydown消费后不再插入。没有keydown时只识别原生input追加的单个insertText空格，以事件内最新原值提交，不先程序trim回写。组合期间、229、粘贴和修改键保持原生语义。可视词槽按目标词数固定，超额文本在末槽完整可编辑，尾空格不扩张数量；此规则不把其他模式的空格改成全局提交。
- 尚未存在词的点击：在用户点击处理器中把选区移至原文末尾，尝试 `execCommand('insertText')` 补最少定位空格，由原生 input 事件一次更新状态。该编辑命令已弃用，但直接赋值无法保留 Undo，目前此窄场景缺少等价标准替代，依据 [MDN execCommand](https://developer.mozilla.org/en-US/docs/Web/API/Document/execCommand)。普通键盘/软键盘录入不依赖它，不在 input/beforeinput 回调中重入命令，不注册全局兜底字符监听。
- 失败语义：编辑命令不支持、拒绝或抛错时不改写原值，不合成字符事件；保留原文末尾焦点，用户仍可用原生空格继续到后词。不得以 value/setRangeText 程序补写兜底而悄悄清空原生编辑历史。
- 自动验证：同目录模型与组件测试；`scripts/practice-word-input-runtime-smoke.cjs` 在生产 Web/Electron 中检查打字→点击后词→撤销/重做，以及编辑命令故障注入。故障注入与真实键盘操作分开记录；实际执行结果见[练习开发文档](../practice-page-development.md#整词输入显示与原生编辑2026-10-19)。
- 人工验收：PC检查词槽宽度、活动线、点击定位、原生编辑、实际缩放及焦点；平板/H5 的系统软键盘、输入法、触摸/横向滚动、页面放大和外接键盘仍待用户真机验收，不据 Chromium 单宿主推断全部浏览器兼容。
- 替换条件：如改用新的标准原生编辑路径，必须在目标浏览器/Electron中同时证明原文、选区、IME及跨词点击的Undo/Redo保持，再删除窄命令与对应失败回退；不得仅因API弃用而改回直接value赋值。

- 2026-10-20公共反馈：可选feedback由调用方提供，公共输入不判题。按Unicode码点提供可见槽状态，原生selection仍为UTF-16；DOM Range跨分段文本累计且排除缺字占位。缺字不补到input，多字不截断，过期反馈不套新值；仅反馈更新不改变选区和手动滚动。仅word:spell显式启用作答聚焦命令（↑↓、Shift+L/J/K及合法绑定），命中后阻止原生输入，长按不重复动作；普通编辑器不透传，IME／229及原生编辑组合继续保留。新生产专项practice-word-spell-public-runtime-smoke.cjs用隔离fixture挂载实际组件，须与真实卡面判题、OS输入法和剪贴板证据分开记录。
