## 9. 每项确认记录与验收

每项从“待提供 / 待核对”变为“已确认映射”时，补齐一条可追踪记录：

1. **稳定 ID 与配置原值**：两者明确对应；若是只有开关的项，明确语义事件。
2. **本地资源路径或本地效果实现入口**：资源跟随练习的真实所有者进入 `assets/`；实现入口与配置映射一起记录，禁止仅写临时文件地址。
3. **来源与授权**：原始来源、权利人 / 授权凭据、许可版本及本项目使用与分发范围；尚未核对则明确写待核对。
4. **时长、体积与格式**：音频记录实际时长 / 文件大小 / 编码；动画记录持续时间、粒子 / 节点预算或所用资源大小，不能用参考常量充当实测值。
5. **音量或基准**：四组音色分别使用自身现有音量字段；切题 / 模拟评测完成记录已确认的基准，不臆造额外偏好。记录削波、突兀响度及与题目媒体冲突的核对结果。
6. **状态与负责人**：待提供 / 待核对 / 已确认映射，补齐日期与确认人；缺项有明确下一步。
7. **验收证据**：原值能命中正确效果，开关与音量有效；首播来自用户演示操作，加载 / 解码 / 自动播放限制失败反馈真实；重复渲染不重播，切题 / 暂停 / 退出清理，装饰层不挡操作；动画遵守减少动态效果偏好。

缺素材时保留配置可编辑与存储能力，演示明确反馈“素材未接入”或不可试听；一个缺项不阻塞其他已确认素材项的控制器验证。交接逐项列出已覆盖、未覆盖与待确认内容，不能以封装完成概括为所有音色已可用。

本清单记录当前映射和缺项；控制封装已经实现，实际能力和验收边界见下节及主文档17.4。清单条目不代表已经存在相应媒体素材，不新增依赖或练习按键逻辑。
