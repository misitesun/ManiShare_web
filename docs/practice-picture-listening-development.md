`PictureListeningExercise` 替代原占位题面。1920×1080 CSS 视口、100% 缩放、默认字号且内容列表关闭时，主图基准为 844×565、(538,134)，音标14px／y727，英文40px／500／y753，中文30px／400／y820，笔记76×30／y872，口语入口234×46／y924；图片圆角20。文字采用自然流，非默认字体和换行会向下推开后续内容，不以文字框高假冒强制单行裁切。

视频原 `VideoSentenceList` 抽为 `PracticePlaybackList`，数据契约位于 `model/practice-playback-list.ts`。视频各模式仍用时间戳、原“句子列表”标题、已听完标记和原选句回调；看图传入01—10题号、播放列表进度及选词回调，不伪造视频进度。

## 播放和交互

- 首次进入及每次有效访问请求当前词条朗读；没有新增切读开关，也不把其他模式的默认值当成开关。`practice-cut-reading` 仅为显式 `picture/listen + sequenceEnabled` 开放访问资格，原28种切读控件白名单不变。
- 继续使用 `usePracticeReading` 的唯一宿主和 `scheduleSentencePlayback` 前置调度：切题音效结束后开始朗读，关闭／失败／缺失提示音沿既有回退；不并播两套声音。
- 顶部播放／暂停和 Shift+L 复用原播放控制；盲听隐藏音标和英文但保留图片与中文；自动切题只由真实 ended 后等待1000ms触发。章节循环与自动下节沿原互斥策略，没有下一章节时自动下节禁用。
- 手动上／下题、Shift切题和Space切题同步题号与朗读，并退出原自动切题意图。内容列表选其他题走同一切题入口；重选当前词条增加访问版本并重播。点击列表／快捷键切题后归焦练习根，保留内部真实操作控件的键盘焦点提示。
- PC非模态列表保持播放；窄屏模态列表阻断背景快捷键和旧播放。关闭不无条件恢复旧音频，选题后按新访问朗读。切题、重置、完成、隐藏、退出、卸载及模态阻断沿现有清理路径，旧访问 ended 不得推进新题。
- 笔记使用 `usePracticeNotes`／`PracticeNotesPanel`；口语入口使用现有 `OralAssessmentDialog`，目标类型为word，仍是原有模拟录制／评分，不增加真实麦克风或评测接口。
- 顶部答案、草稿、设置和全屏、掌握／不熟等原有入口继续复用。掌握／不熟保留本地提示，不伪造学习进度或积分。
