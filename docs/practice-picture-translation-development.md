# 看图学词 · 中译英

## 确认范围

2026-10-26，用户要求“完全参考视频游戏的中译英”，指定图片760×520、与看图沉浸听力共用图片。核对现有组件与状态后，已发布五项方案并收到“确认开始”。本轮只扩展现有 `picture-basic/translate`，不增加路由或正式接口，保留前一轮听力和快捷键优化。

- 布局：复用视频中译英纵向自然流，图片→中文→分段输入；输入与长中文自然向下撑开。
- 数据：十条词例、中文、音标与五份离线WAV同听力，按模式隔离题目ID。包含单词及 `brush teeth` 等短语。
- 行为：局部抄写／默写、翻译显隐、切读、空格与回车提交、方向键跳格、原切题快捷键、正确／错误／查看答案沿共用流程。
- 答案与辅助：按用户最新调整，答对保留760×520封面、手动揭晓仍隐藏，共用逐词／整词展示、笔记、快捷口语、顶栏答案及内容列表。口语目标类型为word，继续使用原模拟评测，不增加麦克风／真实评分接口。
- 本地黄晶：按已确认方案复用视频中译英，本轮初始0、每题首次答对+10，返回已奖励题不重复加，整轮重置清空；没有账户积分或持久化写入。

## 组件与会话归属

全部留在 `src/fsd/pages/practice`。`PracticePage` 显式识别看图中译英，接入 `isSentenceTranslation`、`isSentenceInput` 及已有 `submit-sentence-answer` 分段判题；不把整个picture族改成句子族，也不创建视频播放器。

`SentenceExercise family="picture"` 直接复用视频中译英使用的 `SentenceTranslationExercise` 与 `SentenceAnswerInput`。它们拥有相同的自然流间距、输入控制器和交互；`getSentenceGameLabel` 仅扩展显示身份，`isSentenceGameFamily` 仍只有sentence与audio，其他看图模式不自动获得句子能力。

`PictureTranslationCover` 只替换媒体槽：760×520、圆角16、同一 `picture-scene.png`，通过 `object-cover` 适配指定比例；读音展示仍用 `PracticeReadingOverlay`，状态来自 `usePracticeReading`；点击图片复用朗读／暂停入口，阻断时原生disabled，键盘激活与底栏走同一命令。本轮不下载新图片、不重复生成音源，主图静态遮罩／区域框仍来自同一资源，没有新增词条动态坐标。

正确后与视频相同，进入 `SentenceListeningExercise family="picture"`，使用可选media槽继续展示原760×520图片，移除输入并保留当前英文、中文、笔记与口语入口；手动揭晓的原隐藏规则保持。顶栏答案沿原 `PracticeAnswerPanel` 的中译英变体；局部译文显隐继续生效。手动查看答案本身不加分。

`VideoPracticeLayout variant="picture"`、`PracticePlaybackList` 继续共用上一轮内容入口，传入本模式十题与题号，不传视频时间戳。PC右侧列表及主区／底栏联动、平板/H5模态入口沿既有组件；选其他题复用切题和切读规则，同题不清空作答。

`PracticeFooter` 的看图中译英动作与视频中译英一致，移除该模式旧掌握／不熟入口与命令资格，保留看图听力／口语原配置。本轮不改变已优化的听力 `Shift+←/→ / 空格` 提示，仍区分输入态跳格／提交和答后继续。
