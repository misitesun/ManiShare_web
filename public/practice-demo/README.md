# 练习页技术验证媒体

这里仅存放本项目自行生成的播放器技术验证样例。它们不是课程素材、题目发音、用户录音或设置中任何一个已选音色；不用于替代缺失的业务音视频。页面使用时必须显示“技术验证片段，非课程音视频”。

固定同源 URL 统一由 `src/fsd/pages/practice/model/technical-media-samples.ts` 提供，`PracticeMedia` 对这些 URL 自动显示上述标识。Next 当前没有媒体静态 import 配置，因此使用 `public/practice-demo/`，不为两个验证文件增加 loader、依赖或构建配置。

| 文件 | 自制内容与来源 | 格式 | 验证用途 |
| --- | --- | --- | --- |
| `technical-tone.wav` | 用 Python 标准库 `math`、`struct`、`wave` 从数学正弦生成；440 Hz、最大幅度 0.12、首尾 30 ms 渐入渐出，无采集或第三方音源 | 2 秒，16 kHz，16 bit PCM，单声道，64,044 字节 | 验证真实音频加载、播放／暂停、进度、音量／倍速、结束、互斥与清理 |
| `technical-video.mp4` | 用 macOS AVFoundation `AVAssetWriter` 与自行填充的纯色像素帧生成；320×180，24 fps，共 48 帧，无人物、课程图像、屏幕录制或音轨 | 2 秒，MP4，H.264 Baseline Profile，Level 1.2，3,876 字节 | 验证真实视频加载、播放／暂停、进度、倍速、结束与清理；静音片段不证明音轨播放 |

生成没有安装依赖、联网或使用参考站资源。视频生成时仅调用本机编码器；播放器运行不需要 Swift、Python 或编码权限。

文件已检查 WAV 采样参数以及 MP4 的时长、分辨率和 H.264 配置。文件存在和控制器替身单测不等于浏览器实际播放通过；PC Web／Electron 需以生产静态资源、MIME 和实际媒体事件验证。平板／H5 的播放、软键盘、触摸、系统音量和真机兼容仍待用户验收。

后续真实课程资源应跟随练习 owner 放置，并单独提供来源／使用条件。不能把这两个验证样例填入课程媒体缺项或特效音色清单，声称该业务素材已落实。
