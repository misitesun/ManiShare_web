固定同源地址为/practice-demo/video-listening/dialogue.wav；model/video-listening-demo.ts按实际PCM帧数定义十段起止时间。六模式各自会话只挂载一个音频元素和这一音源，切题定位同一音轨，不新增十份媒体文件。听力以实际currentTime驱动进度、字幕及逐句重复，默认不自动播放；自查／指法／口语／拼块／中译英沿局部切读偏好，关闭切读仅定位，显式点击封面／朗读时播放当前句段，段末暂停、不自动切题，完成由各自答题／继续流程控制，不以听完末句直接完成。不预加载全部独立WAV。口语开始模拟录制时暂停音轨并撤销待播，结果示例回放从当前句起点播放同一资源。拼块／中译英判题先暂停、取消待播，手动朗读等判题提示音结束；答案隐藏封面不卸载媒体。本次没有修改WAV内容。

每个句段都包含“句首1秒静音 → 原朗读 → 句末1秒静音”，第一句前、最后一句后也保留。手动切句从该句的前置静音开始；听力单句每次重复都播放完整句段，句末停在后置静音结束后暂停，听完记录及最后完成弹窗也在该句后置静音结束后处理；其余五模式同样播放完整句段后暂停，但完成由各自作答流程决定。静音期间显示所属句子的字幕／解析，下一句开始时间仍与前一句结束时间相接。听力连续播放时，上一句后置1秒与下一句前置1秒合计约2秒留白（1×时）。
