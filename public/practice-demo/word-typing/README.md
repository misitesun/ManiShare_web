# 单词游戏通用示例朗读（原十词）

本目录属于`pages/practice`，为单词游戏六模式中的原十个目标词提供对应朗读；不是正式课程录音、用户录音或口语评分素材。保留原URL，不复制或重新合成已有音频。补充九个目标词、三十条例句与十条句中练义整句见[补充音源](../word-reading/README.md)。

按用户“切读、朗读按句子游戏接入”的要求，于2026-10-22复用句子样例的生成方式：本机已安装的macOS `say`、Samantha（en_US）、160词／分钟离线合成，每次只朗读目标单词，末尾句号仅用于停顿。通过系统`afconvert`保存为22,050Hz、16bit PCM、单声道WAV；没有联网、安装依赖或借用整句录音／技术纯音。

- `woman.wav`：woman
- `man.wav`：man
- `girl.wav`：girl
- `boy.wav`：boy
- `book.wav`：book
- `apple.wav`：apple
- `water.wav`：water
- `sun.wav`：sun
- `green.wav`：green
- `happy.wav`：happy

`word-demo-reading.ts`统一按目标词匹配这些样例；`practice-demo.ts`为六个单词模式填入对应目标词音源，题目身份和题量保持。通用评测弹窗在当前题目已有音源时优先用该音源，否则仅对表内单词复用对应样例；缺项不补查、不以其他词或技术纯音替代。复用`usePracticeReading`、朗读宿主和句子现有播放前置调度：切读开启时进入新题自动请求一次，先等待当次切题提示音真正结束；音效关闭／缺失／失败时直接放行。切读关闭不自动请求，但朗读按钮和配置快捷键仍可播放／暂停本题。评测回放独立请求当前题目音频，录音和评分期间停止朗读；切题、重练、弹窗、页面隐藏、暂停和卸载沿现有取消与访问标识保护，不补播旧题，不预加载整组音频。

生成时已读取文件格式、非空音频帧、时长与大小；这是资源结构检查，不是实际播放验收。未运行项目测试、构建或浏览器／Electron播放，音质、自动播放权限、音效顺序及PC／平板／H5实际兼容由用户验收。后续正式数据由所属适配器替换音源，不在浏览器发起TTS或缺项补全请求。
